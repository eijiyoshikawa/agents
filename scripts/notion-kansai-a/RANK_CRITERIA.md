# 見込み度合い A〜D 判定基準（DB_顧客管理）

営業観点：採用SNS／人材紹介の受注確度を「規模 × エリア」で4段階に分類。

| ランク | 基準（ひとことで） | 詳細条件 |
|--------|------------------|----------|
| **A** | 関西の中堅・大手 | 従業員 **30名以上** ＋ 住所が **大阪府・京都府・兵庫県** のいずれか |
| **B** | 関西以外の中堅・大手 | 従業員 **30名以上** ＋ 上記3府県以外（**滋賀県**・東京都など全国） |
| **C** | 中小規模（全国） | 従業員 **11〜29名**（エリア不問） |
| **D** | 小規模 | 従業員 **10名以下** |

補足:
- 規模で 30名以上＝A/B、11〜29名＝C、10名以下＝D に三分割し、30名以上だけ関西/関西以外でA/Bに分ける。
- 関西＝**大阪・京都・兵庫**の3府県。**滋賀県は関西以外（B）扱い**。
- 従業員数が**未入力**のレコードは現状いずれにも該当しない（数値が入っていないため）。
- 既に手動で上位ランクを付けた大手は維持（スクリプトは同じ値をスキップ）。
- A は初回4府県（滋賀含む）で実行済みのため、滋賀の30名以上は一旦Aになっているが、`run:b` で B に移し替わる。

## コピペ用（プレーンテキスト）

```
【見込み度合い 判定基準】
A：従業員30名以上 ＋ 関西（大阪・京都・兵庫）
B：従業員30名以上 ＋ 関西以外（滋賀含む全国）
C：従業員11〜29名（エリア不問）
D：従業員10名以下
※従業員数が未入力のものは対象外
```
