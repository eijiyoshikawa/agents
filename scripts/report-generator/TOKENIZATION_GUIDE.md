# Slides マスターテンプレ トークン化ガイド（ワンタイム作業）

Apps Script 自動充填を使うための **1回だけの準備**。元テンプレ『【テンプレ】分析レポート』
(`1CKpQVi9juA34NV4z07VJhj4pTNK4BGm6IbXFy3IpKQM`) を複製し、各空欄を下表の `{{TOKEN}}` に
置き換えて「マスターテンプレ」を作る。完了したらその ID を `Code.gs` の `TEMPLATE_ID` に設定。

> 💡 作業後、Claude が MCP でデッキ本文を読み取り、トークンの抜け漏れを検証できます。
> 「マスターのトークン化を確認して」と依頼してください。

## 手順
1. 元テンプレを複製（ファイル > コピーを作成）。名前例: `【マスター】分析レポート_tokenized`
2. 下表の「置換後」に従って、各スライドのテキストを書き換える
   （Google スライドの「検索と置換」も活用可。ただし重複する `0,000` 等は手動で個別に）
3. グラフ/画像を入れたい位置に**空のテキストボックス**を置き、`{{IMG_...}}` だけを入力
4. 表スライド(8,9)は、テンプレの表を削除し、**空のテキストボックス**に `{{TBL_...}}` を入力
   （その位置・大きさに自動で表が生成される）
5. 完了後、`TEMPLATE_ID` にこのマスターの ID を設定

## 置換マップ

### Slide 1（表紙）
| 元の文字 | 置換後トークン |
|---|---|
| `202●年●月` | `{{REPORT_YM}}` |
| 「作成者」の値欄 | `{{CREATED_BY}}` |
| `20●●年●月●日 作成` | `{{CREATED_DATE}} 作成` |

### Slide 4（総括）
| 元の文字 | 置換後トークン |
|---|---|
| `『●●●』@demo_username` | `『{{ACCOUNT_NAME}}』{{ACCOUNT_HANDLE}}` |
| `運用期間（20〇〇年〇〇月〜〇〇月）` | `運用期間（{{OPERATION_PERIOD}}）` |
| `運用目的　採用応募の獲得 / ブランド認知 / フォロワー増加` | `運用目的　{{OPERATION_PURPOSE}}` |
| 基本情報側の `テキスト` | `{{SUMMARY_TEXT}}` |
| 結果側の `テキスト` | `{{RESULT_TEXT}}` |

### Slide 6（アカウント分析）
> 数字の箱が多い。**各箱を1つずつ**トークン化する（同じ `0,000` でも別トークン）。
| 元の箇所 | 置換後トークン |
|---|---|
| `データ取得日：〇〇年〇月〇日` | `データ取得日：{{DATA_FETCH_DATE}}` |
| フォロワー推移 開始時 | `{{FOLLOWERS_START}}` |
| フォロワー推移 現在 | `{{FOLLOWERS_CURRENT}}` |
| フォロワー 前回比% | `{{FOLLOWER_CHANGE_PCT}}` |
| いいね 数 / 前月比% | `{{LIKES}}` / `{{LIKES_PCT}}` |
| コメント 数 / 前月比% | `{{COMMENTS}}` / `{{COMMENTS_PCT}}` |
| シェア 数 / 前月比% | `{{SHARES}}` / `{{SHARES_PCT}}` |
| 投稿数（累計） | `{{POST_COUNT}}` |
| 投稿頻度（月間） | `{{POST_FREQ}}` |
| 動画視聴数 / 前月比% | `{{VIDEO_VIEWS}}` / `{{VIDEO_VIEWS_PCT}}` |
| PFアクセス / 前月比% | `{{PF_ACCESS}}` / `{{PF_ACCESS_PCT}}` |
| （リーチを使う場合） | `{{REACH}}` / `{{REACH_PCT}}` |
| グラフ枠（任意） | 空テキストボックスに `{{IMG_OVERVIEW_28D}}`（必要に応じ `{{IMG_AUDIENCE_28D}}`） |

### Slide 8（投稿分析）
- テンプレの表を削除 → 空テキストボックスに `{{TBL_POST_ANALYSIS}}`

### Slide 9（伸びた投稿）
- テンプレの表を削除 → 空テキストボックスに `{{TBL_POPULAR_POSTS}}`

### Slide 10 / 11 / 12（よかった投稿 ①②③）
> スライド10=①、11=②、12=③。番号を合わせる。
| 元の文字 | 置換後トークン（10→_1 / 11→_2 / 12→_3） |
|---|---|
| `投稿日：202〇年〇月〇日` | `投稿日：{{POST_DATE_1}}` |
| `テーマ：` の値 | `{{POST_THEME_1}}` |
| 評価ポイントの `テキスト` | `{{POST_EVAL_1}}` |
| コメントピックアップの `テキスト` | `{{POST_COMMENT_1}}` |
| 画像枠（任意） | 空テキストボックスに `{{IMG_POST_1}}` |

### Slide 14 / 15（次回施策）
> 両スライドに「今後の施策②」がある。14→`_2`、15→施策①は`_1`に割り当て。
| 元の箇所 | 置換後トークン |
|---|---|
| 振り返り | `{{REFLECTION}}` |
| 現状の課題 | `{{CURRENT_ISSUE}}` |
| 目標達成の為のアクションプラン | `{{ACTION_PLAN}}` |
| 今後の施策① | `{{FUTURE_MEASURE_1}}` |
| 今後の施策② | `{{FUTURE_MEASURE_2}}` |

## デプロイ（マスター作成後）
1. https://script.google.com で新規プロジェクト作成
2. `Code.gs` / `appsscript.json` を貼り付け
3. `TEMPLATE_ID` をマスターの ID に設定
4. `generateReportForFolder('<提出分フォルダID>')` を実行 → 初回は権限承認
5. 同フォルダの `report_data.json` を読み、複製＋流し込み → デッキURLが返る
