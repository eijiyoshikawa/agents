# レポート制作・運用コスト試算（社内）

対象: 採用SNS分析レポート（Google Slides 15枚）1本あたりの社内コスト。
方式: スクショ → Claude(MCP)抽出 → Apps Script 自動充填 → 人レビュー。

> 前提レート（社内目安・調整可）: 人件費 **¥3,000/時**、Claudeは **Maxプラン内で追加API費用 ¥0**、
> Google Workspace / Apps Script は既存契約内で **追加 ¥0**。

## 1. 初期構築コスト（一度きり・全クライアント共通で再利用）
| 項目 | 内容 | 時間/費用 |
|------|------|-----------|
| テンプレ構造解析・座標確定 | Inspect.gs で全15枚をダンプ→Code.gsに反映 | Claude作業（¥0）+ 人確認 0.5h |
| レンダラ実装（Code.gs） | 位置ベース流し込み・表・画像対応 | Claude作業（¥0）+ 人確認 0.5h |
| 動作確認・微調整 | 生成→検証→座標修正 | 人 1.0h |
| **小計** | | **約2.0h ≒ ¥6,000（追加API ¥0）** |

→ 構築は完了済み。以降のクライアント・月次では再利用するため**1本あたりには乗らない**。

## 2. 1本あたり 限界コスト（月次・クライアント追加ごと）
| 工程 | 担当 | 時間 | 費用 |
|------|------|------|------|
| スクショ収集（管理画面DL） | スタッフ | 15分 | ¥750 |
| 数値抽出（OCR×ビジョン） | Claude(Max) | 5–10分 | ¥0 |
| デッキ自動生成（Apps Script実行） | 自動 | 1分 | ¥0 |
| narrative作成（総括・課題・施策・コメント抜粋） | 人 | 20分 | ¥1,000 |
| レビュー・体裁調整・画像手貼り | 人 | 15分 | ¥750 |
| **合計** | | **約55分** | **約¥2,500/本** |

※ 追加のAPI/ツール費用は発生しない（Maxプラン内・Workspace内）。
※ コストの実体は **ほぼ人件費（約45分の人作業）** のみ。

## 3. 自動化の効果（Before/After）
| | 手作業（従来） | 自動化（本方式） |
|---|---|---|
| 1本あたり所要 | 約3–4時間（転記・整形） | **約55分** |
| 1本あたり社内費用 | 約¥9,000–12,000 | **約¥2,500** |
| 転記ミス | 起きやすい | 抽出値を機械流し込みで低減 |
| スケール | 線形に増加 | クライアント追加の限界コストが小さい |

→ **1本あたり約70–75%の工数削減**。月10本なら従来 約¥100,000 → 約¥25,000。

## 4. 月次ランニング（固定費の考え方）
- Claude Max プラン: 既存の月額内（このレポート用途の**追加 ¥0**、複数業務で共用）。
- Google Workspace / Drive / Apps Script: 既存内、**追加 ¥0**。
- 変動費: 実質ゼロ（人時間のみ）。

## 5. 前提・除外
- 上記は**社内制作コスト**。クライアント向けの広告費・運用フィー等は含まない（別途要望時に作成）。
- 「細かい掲載（全投稿明細・期間トレンド・属性）」を行う場合、抽出対象が増えるため
  **数値抽出/レビュー時間が +15–30分/本** 程度増える見込み（API費用は引き続き ¥0）。
- レートは社内目安。実際の人件費単価に置き換えて再計算可能。
