### 最初に着手する 3 つと理由

1. **/run-pipeline（#1 + #6 + #17）** — 中核業務（提案資料・戦略立案）の起動摩擦が最大のボトルネック。qa-gate による機械検証を各ステップに挟むことで、差し戻しが「気づいたら」から「必ず」に変わる。
2. **/daily-report（#2 + #8 + #9）** — 「一番減らしたい」と回答された作業そのもの。集計の下ごしらえをスクリプトで機械化し、AI は診断・計画の一次案に集中する。
3. **Ops Cockpit（#15）** — 上記 2 つの出力を1画面に集約する受け皿。静的 HTML 生成なので破壊リスクゼロで、日次確認 → レポート → 意思決定の動線が繋がる。

（余力で #3 /sns-batch と OPERATIONS.md も同時に整備 → 実際に整備済み）
