# リスキリング助成金対応 LMS — 設計 & コスト計算

研修動画を視聴し、**助成金審査に耐える受講ログ**を残すマルチテナント LMS の設計とコスト計算。

- **対象助成金**: 人材開発支援助成金 **事業展開等リスキリング支援コース**
- **提供形態**: クライアント提供（SaaS / 受託）
- **本ディレクトリの範囲**: 設計とコスト計算のみ（**実装は別リポジトリ**）

## 3行サマリ
1. **作れる。** 技術的難所はなく、肝は「早送り・放置を排した実視聴カバレッジ + 確認テスト + 修了証」で助成金審査に耐える証跡を機械生成すること。
2. **開発**は MVP 約 95 人日（内製なら追加 API 費ゼロ）。
3. **ランニング**は動画配信分数が支配的で、受講者 100名で ~¥3.3万/月、500名で ~¥30万/月。SaaS 提供では**視聴量に応じた従量課金で転嫁**するのが損益の勘所。
