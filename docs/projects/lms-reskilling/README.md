## 3行サマリ
1. **作れる。** 技術的難所はなく、肝は「早送り・放置を排した実視聴カバレッジ + 確認テスト + 修了証」で助成金審査に耐える証跡を機械生成すること。
2. **開発**は MVP 約 95 人日（内製なら追加 API 費ゼロ）。
3. **ランニング（確定前提: 受講者200名/視聴12h・人）は ≒ ¥34,000/月**。受講者従量 ¥1,200/名なら粗利率 ~86%、損益分岐は約10名。
