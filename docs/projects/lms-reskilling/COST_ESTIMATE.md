# リスキリング助成金対応 LMS コスト計算

> 対象: 事業展開等リスキリング支援コース向け マルチテナント LMS（SaaS/受託）
> 本書は **① 開発工数** と **② 月次ランニングコスト** の 2 本立て。
> 金額は 2026-07 時点の一般的な公開価格に基づく**概算**。為替は $1 = ¥155 で換算。
> 最終更新: 2026-07-15 / 検証: Finance・Tech Lead

## 1. 開発工数（Phase 1 = MVP）

## 2. 月次ランニングコスト — 構成要素

| 項目 | サービス例 | 課金モデル | 備考 |
|------|-----------|-----------|------|
| ホスティング | Vercel Pro | 定額 $20/月 | 社内標準 |
| DB | Supabase Pro / Neon | 定額 ~$25/月〜 | RLS・バックアップ込 |
| **動画 保管** | Cloudflare Stream | $5 / 1,000分・月（保管） | コンテンツ総尺に比例 |
| **動画 配信** | Cloudflare Stream | $1 / 1,000分（視聴） | **最大のコストドライバー** |
| オブジェクトストレージ | R2 / S3 | ~$0.015/GB | PDF・エクスポート |
| メール | Resend / SES | ~$0〜 | リマインド |
| 監視・ログ | Vercel/軽量SaaS | ~$0〜10 | |
| ドメイン/証明書 | — | ~¥1,500/月按分 | |

> **原理**: 定額部分（ホスティング+DB ≒ 月 $45 / ¥7,000）はテナント数によらずほぼ一定。変動費は **動画の視聴分数**にほぼ線形。よって「受講者数 × 1人あたり視聴時間」でコストが決まる。

### 動画配信コストの計算式
```
月間視聴分数 = 受講者数 × 1人あたり月間視聴時間(分)
配信費(円)   = 月間視聴分数 / 1000 × $1 × 155
保管費(円)   = コンテンツ総尺(分) / 1000 × $5 × 155   （毎月）
```

## 3. シナリオ別 月次ランニングコスト

前提: コンテンツ総尺 = 各シナリオ記載。1 受講者は在籍月に平均その総尺程度を視聴（復習含め ×1.2）。

### 小規模 — 立ち上げ / 数社
- テナント 3 社、受講者 **100 名/月**、コンテンツ **20時間(1,200分)**、視聴 1人あたり 1,440分/月

| 項目 | 計算 | 月額(円) |
|------|------|:--------:|
| ホスティング+DB | 定額 | 7,000 |
| 動画 保管 | 1,200/1000×$5×155 | 930 |
| 動画 配信 | 100×1,440=144,000分 /1000×$1×155 | 22,320 |
| ストレージ/メール/監視/他 | | 3,000 |
| **合計** | | **≒ ¥33,000/月** |

### 中規模 — 受託が乗ってきた段階
- テナント 10 社、受講者 **500 名/月**、コンテンツ **50時間(3,000分)**、視聴 1人あたり 3,600分/月

| 項目 | 計算 | 月額(円) |
|------|------|:--------:|
| ホスティング+DB | 定額(やや上位) | 10,000 |
| 動画 保管 | 3,000/1000×$5×155 | 2,325 |
| 動画 配信 | 500×3,600=1,800,000分 /1000×$1×155 | 279,000 |
| ストレージ/メール/監視/他 | | 8,000 |
| **合計** | | **≒ ¥300,000/月** |

### 大規模 — 本格 SaaS
- テナント 30 社、受講者 **2,000 名/月**、コンテンツ **100時間(6,000分)**、視聴 1人あたり 7,200分/月

| 項目 | 計算 | 月額(円) |
|------|------|:--------:|
| ホスティング+DB | 上位プラン/専用 | 30,000 |
| 動画 保管 | 6,000/1000×$5×155 | 4,650 |
| 動画 配信 | 2,000×7,200=14,400,000分 /1000×$1×155 | 2,232,000 |
| ストレージ/メール/監視/他 | | 25,000 |
| **合計** | | **≒ ¥2,290,000/月** |

> **重要**: 大規模では動画配信費が支配的（97%超）。**受講者課金 or 従量課金モデルで転嫁必須**（§4）。CDN 帯域割引・年間コミットで単価を下げる余地あり。

## 4. 価格転嫁・課金モデル（SaaS 提供時）

配信費が受講量に比例するため、**受講者従量 or 視聴時間従量**が損益上安全。

| モデル | 例 | 特徴 |
|-------|-----|------|
| 受講者従量 | ¥800〜1,500 / 受講者・月 | 分かりやすい。視聴が重いと薄利化リスク → 視聴時間に上限や超過課金を併設 |
| テナント定額 + 従量 | 基本 ¥30,000/月 + ¥500/受講者 | 小口テナントも黒字化 |
| 視聴時間従量 | ¥X / 視聴時間 | コスト構造に最も忠実 |

### 損益ラフ試算（中規模・受講者従量 ¥1,200/名）
- 売上: 500 名 × ¥1,200 = **¥600,000/月**
- 直接原価(ランニング): **¥300,000/月**
- **粗利 ≒ ¥300,000/月（粗利率 50%）** ＋ 初期構築費（受託なら別途）。
- ※ 運用・サポート・営業の人件費（社内エージェント）は追加 API 費用ゼロだが、実働は消費する点に留意。

## 5. コスト最適化の打ち手

1. **配信単価の削減** … 年間コミット / 大量割引 / 自前 R2+HLS へ切替（工数増とのトレードオフ）。
2. **視聴の無駄削減** … 復習視聴もカバレッジ済み区間は再配信最小化（プレイヤーキャッシュ）。
3. **画質の最適化** … 講義動画は 720p 上限で十分。ビットレート抑制で配信分数あたりコスト減。
4. **保管の整理** … 旧コースはコールドストレージ or 削除ポリシー。
5. **定額部分の据え置き** … テナントが増えても DB/ホスティングは段階的増強で足りる。
