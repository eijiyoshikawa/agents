# コスト計算（確定前提・実数）

> 本書は「想定受講者数を1つ確定」した上での実数計算。
> [COST_ESTIMATE.md](./COST_ESTIMATE.md) のシナリオ表を**この確定前提で置き換える**（視聴強度の想定も現実的値に補正）。
> 為替 $1 = ¥155。金額は概算。最終更新: 2026-07-15 / 検証: Finance・Tech Lead

---

## 1. 確定した前提（ベースライン）

| パラメータ | 値 | 補足 |
|-----------|-----|------|
| テナント（クライアント企業） | **5 社** | 立ち上げ〜受託が乗った初期の現実値 |
| アクティブ受講者 | **200 名** | 常時受講中の人数 |
| コンテンツ総尺 | **30 時間（1,800 分）** | 1コース想定 |
| **月間視聴時間 / 受講者** | **12 時間（720 分）** | ★最重要レバー。リスキリングは2〜3ヶ月で消化する前提の月割 |
| 視聴上限速度 | 2.0x | 超過分は実視聴に計上しない |
| 受講者従量単価（SaaS） | ¥1,200 / 名・月 | 損益試算用（§4） |

> **なぜ 12時間/月・人か**: リスキリング訓練（30h級）は一気見せず 2〜3 ヶ月かけて消化するのが実態。旧シナリオ表の「500名で¥30万」は視聴強度を 60h/月・人 と重く置いた上限ケース。本ベースラインは現実的な 12h に補正している（§5 に感度分析）。

## 2. 月次ランニングコスト（実数）

計算式（DESIGN/COST_ESTIMATE と同じ）:
```
月間視聴分数 = 受講者数 × 月間視聴時間(分) = 200 × 720 = 144,000 分
配信費 = 144,000 / 1000 × $1 × 155 = ¥22,320
保管費 = 1,800  / 1000 × $5 × 155 = ¥1,395  （毎月）
```

| 項目 | 計算 | 月額(円) |
|------|------|:--------:|
| ホスティング (Vercel Pro) | 定額 $20 | 3,100 |
| DB (Supabase/Neon Pro) | 定額 $25 | 3,900 |
| 動画 保管 | 1,800分 | 1,395 |
| 動画 配信 | 144,000分 | 22,320 |
| ストレージ (R2/S3) | PDF・エクスポート | 500 |
| メール (Resend/SES) | リマインド | 300 |
| 監視・その他・ドメイン按分 | | 2,500 |
| **月次合計** | | **≒ ¥34,000/月** |

## 4. ユニットエコノミクス（SaaS 提供時・受講者従量 ¥1,200/名）

| 指標 | 値 |
|------|-----|
| 月次売上 | 200名 × ¥1,200 = **¥240,000/月** |
| 月次直接原価（ランニング） | **¥34,000/月** |
| **月次粗利** | **¥206,000/月（粗利率 86%）** |
| 受講者1名あたり原価 | ¥34,000 / 200 = **¥170/名・月** |
| 受講者1名あたり粗利 | ¥1,200 − ¥170 = **¥1,030/名・月** |
| 損益分岐 受講者数 | 定額¥10,000 ÷（¥1,200−¥112変動）≒ **約 10 名**で黒字化 |

- **初期開発費（MVP 約95人日）は別**。内製なら追加API費ゼロ、外注換算 約380〜475万円。
- 受託モデルなら初期構築費を別途請求 → ランニング粗利は上記が丸残り。
- サポート・営業の実働（社内エージェント）は現金コスト外だが工数は消費。

### 初期開発費の回収
- 内製（現金¥0）: ランニング粗利 ¥206,000/月がそのまま利益 → 実質**初月から黒字**。
- 外注（¥400万想定）: 粗利 ¥206,000/月 ÷ → **約 20 ヶ月で回収**。受講者を増やせば短縮。

## 5. 感度分析 — 効くのは「視聴時間 × 受講者数」だけ

配信費は `受講者数 × 月間視聴時間` にほぼ線形。他は誤差。

### 月間視聴時間/人 を振る（受講者200名固定）
| 月間視聴/人 | 配信費/月 | ランニング合計/月 | 粗利率(¥1,200/名) |
|:-----------:|:--------:|:----------------:|:----------------:|
| 6 時間 | ¥11,160 | ≒ ¥23,000 | 90% |
| **12 時間(基準)** | **¥22,320** | **≒ ¥34,000** | **86%** |
| 24 時間 | ¥44,640 | ≒ ¥56,000 | 77% |
| 48 時間 | ¥89,280 | ≒ ¥101,000 | 58% |

### 受講者数を振る（視聴12h/人固定）
| 受講者 | 配信費/月 | ランニング合計/月 | 売上(¥1,200) | 粗利/月 |
|:------:|:--------:|:----------------:|:-----------:|:------:|
| 50 | ¥5,580 | ≒ ¥16,000 | ¥60,000 | ¥44,000 |
| **200(基準)** | **¥22,320** | **≒ ¥34,000** | **¥240,000** | **¥206,000** |
| 500 | ¥55,800 | ≒ ¥69,000 | ¥600,000 | ¥531,000 |
| 1,000 | ¥111,600 | ≒ ¥126,000 | ¥1,200,000 | ¥1,074,000 |

> **示唆**: 小規模では**定額費（ホスティング+DB ≒ 月¥7,000）が相対的に大きく**、視聴が軽ければ配信費は小さい。受講者/視聴が増えて初めて配信費が支配的になる。従量課金で転嫁している限り、規模拡大とともに粗利率はむしろ安定〜改善する。
