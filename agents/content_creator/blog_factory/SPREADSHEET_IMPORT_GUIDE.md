# スプレッドシート取り込み手順（作業メンバー向け）

ブログ記事150本を、Googleスプレッドシートに取り込んでコピペ作業しやすくするための手順です。

対象シート: https://docs.google.com/spreadsheets/d/1gGkAsdFVQmD-sAezPJkrAqrnq4rF2MSza2GRwudu-xs/edit

取り込むファイル: **`articles_for_sheets.csv`**（日本語ヘッダー＋「入力済み」作業列つき・150記事）
- ダウンロード: リポジトリ `agents/content_creator/blog_factory/articles_for_sheets.csv`
- 文字コードは UTF-8（BOM付き）なので、そのまま取り込めば文字化けしません。

## 列構成（15列）
| 列 | 内容 | WordPress入力先 |
|----|------|----------------|
| 記事番号 | 001〜150 | （管理用） |
| 入力済み | 空欄。作業時にチェックを入れる | （管理用） |
| カテゴリ | 売買・購入／…／テナント仲介 | カテゴリー |
| 記事タイトル | H1兼タイトル | 投稿タイトル |
| サブタイトル | 導入の補足見出し | 本文冒頭など任意 |
| 本文 | 見出し・表・FAQ込みの本文（Markdown） | 本文 |
| メインキーワード | 狙う主KW | （SEO管理用） |
| サブキーワード | 関連KW（; 区切り） | （SEO管理用） |
| メタディスクリプション | 110〜120字 | SEOプラグインのメタ |
| キャプション(alt) | アイキャッチ画像のalt/説明 | 画像のaltテキスト |
| タグ | WordPressタグ（; 区切り） | タグ |
| スラッグ | URL用の半角英数 | パーマリンク |
| 文字数 | 本文の文字数（目安） | （確認用） |
| エリア | 東京・首都圏 | （管理用） |
| ステータス | draft | （管理用） |

## 取り込み手順（インポート方式・推奨）

### A. 既存シートに取り込む場合
1. 対象のGoogleスプレッドシートを開く
2. メニュー **ファイル > インポート** をクリック
3. **アップロード** タブで `articles_for_sheets.csv` を選択
4. インポート場所：
   - まっさらにするなら **「スプレッドシートを置換する」**
   - 新しいタブに入れるなら **「新しいシートを挿入する」**（既存データを残せるので安全）
5. 区切り文字：**「自動的に検出する」**（またはカンマ）
6. 「データを取り込む」をクリック

> 本文セルには改行や記号（#・表の `|` など）が含まれますが、引用符で囲ってあるため1記事=1行に正しく収まります。

### B. 新しいスプレッドシートとして開く場合
1. Googleドライブで **新規 > ファイルのアップロード** で `articles_for_sheets.csv` をアップロード
2. アップロードしたファイルを右クリック **> アプリで開く > Googleスプレッドシート**

## 作業を進めやすくする初期設定（任意）
- **1行目を固定**：表示 > 固定 > 1行（見出しを常に表示）
- **「入力済み」列をチェックボックスに**：B列を選択 > 挿入 > チェックボックス（WordPress投入済みをチェックして進捗管理）
- **本文列の折り返し**：F列を選択 > 表示形式 > 折り返し > クリップ（行が縦に伸びず一覧が見やすい）
- **フィルタを付ける**：データ > フィルタを作成（カテゴリやステータスで絞り込み）

## WordPressへの入力フロー（1記事ずつ）
1. 「入力済み」が空の行を選ぶ
2. 「記事タイトル」→ WordPressの投稿タイトルへ
3. 「本文」セルをコピー → 本文へ貼り付け（Markdown対応エディタ／プラグイン利用、または見出し・表を手動整形）
4. 「メタディスクリプション」「タグ」「カテゴリー」「スラッグ」「キャプション(alt)」を該当欄へ
5. 公開後、「入力済み」にチェック

## CSVを作り直したいとき
記事を追加・修正したら、リポジトリで次を実行すると両CSVが再生成されます。
```bash
cd agents/content_creator/blog_factory
python3 build_csv.py   # articles.csv と articles_for_sheets.csv を更新
```
更新後、上記「取り込み手順」で再インポートしてください。
