# 記事テンプレート / 品質基準（アークホーム ブログ）

`/agents/seo_aieo/SEO_CHECKLIST_112.md` のカテゴリ3（コンテンツ品質）・カテゴリ4（マークアップ）準拠。
1記事 = `articles/NNN-slug.md`。YAML front-matter ＋ 本文Markdown で構成する。

## front-matter スキーマ
```yaml
---
id: "001"                     # 3桁連番
category: "売買・購入"          # 売買・購入 / 売買・売却 / お金・ローン / 賃貸 / エリア / その他
title: "..."                  # H1兼title。狙うKWを前方・全角32文字前後
subtitle: "..."               # 導入の補足見出し（1文）
slug: "chuko-mansion-nagare"  # 半角英数ハイフン（SEO #5）
target_keyword: "中古マンション 購入 流れ"   # メインKW（#16 一番最初に決める）
sub_keywords:                 # 関連KW・表記ゆれ（#36/#39）
  - "中古マンション 内見"
  - "購入 諸費用"
meta_description: "..."        # 110〜120字（#57）
caption: "..."                # アイキャッチ画像のalt/キャプション案（#60/#61）
tags:                         # WordPressタグ 3〜6個
  - "中古マンション"
area: "東京・首都圏"
company: "アークホーム"
status: "draft"               # draft / approved
---
```

## 本文の型（2,500〜3,000文字）
```
（リード文 150〜250字）
  - 読者の悩み → この記事で分かること → 結論の予告。狙うKWを自然に1回。

## 見出し1（##＝h2）        ← h2は4〜6個
（200〜400字）
### 小見出し（###＝h3）     ← 各h2に2〜3個が目安（#42）
…

## まとめ
（150〜250字。要点の再掲＋次の一歩＝CTA）

> CTA例：東京・首都圏で○○をご検討なら、アークホームの無料相談へ。
```

### 構成の必須要素
- [ ] 冒頭に「この記事でわかること」の箇条書き（簡易目次・#29）
- [ ] h2は4〜6個、各h2配下にh3を2〜3個（#41/#42/#48）
- [ ] 表（比較・費用・相場）を最低1つ → Markdown表（#53）
- [ ] 箇条書きリストを適宜（#54）
- [ ] 数字・相場・手順など具体性を入れる（一般的な目安として記載・断定回避）
- [ ] 内部リンク候補を本文末「関連記事」に2〜3個（#64アンカーは内容を表す）
- [ ] まとめに行動喚起（CTA）

## ライティング規約（AI臭の排除）
- テンプレ的な「いかがでしたか？」を使わない
- 同じ語尾の連続を避ける／一文を長くしすぎない
- KWを不自然に詰めない（#37/#38）。表記ゆれは自然な範囲で
- 数値・制度は「2026年時点の一般的な目安」と明示し、最新確認を促す
- 専門用語は初出で一言かみ砕く（信頼感＋親しみやすさ）

## エリア（ローカルSEO）
- titleか本文に「東京」「首都圏」または具体エリア名を入れる（#15）
- エリア特化記事は、家賃/価格相場・交通・子育て/通勤の観点を必ず含める
