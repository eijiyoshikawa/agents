# 画像回収・WordPress登録ガイド（ブログ150記事）

各記事に入れる画像を、フリー素材から効率よく回収し、WordPressのメディアライブラリへ
登録するための運用ガイドです。記事ごとの指示書は **`articles_image_brief.csv`**（150行）。

## まず使うファイル
- **`articles_image_brief.csv`** … 記事ごとの画像ブリーフ（下記の列）
  - 記事番号 / カテゴリ / 記事タイトル
  - 画像枚数の目安
  - アイキャッチ_ファイル名（命名規則統一済み）
  - アイキャッチ_alt（そのまま代替テキストに使える）
  - 検索キーワード(日) / 検索キーワード(英)
  - 本文中画像のヒント

> スプレッドシートに取り込む場合は、本文CSV（`articles_for_sheets.csv`）とは別タブに
> このCSVをインポートすると、画像回収の進捗管理がしやすくなります。

## おすすめフリー素材サイト（商用利用可）
| サイト | 特徴 | クレジット |
|--------|------|-----------|
| 写真AC | 日本の人物・住宅・街並みが豊富。日本向け記事に最適 | 原則不要（無料会員はDL数に制限） |
| Unsplash | 高品質・おしゃれ。英語キーワードで検索 | 不要 |
| Pexels | 写真・動画。英語キーワードで検索 | 不要 |
| Pixabay | 写真・イラスト・図解素材 | 不要 |
| O-DAN | 複数のフリー素材サイトを横断検索 | 各サイトの規約に従う |

### 検索のコツ
- **日本の人物・室内・街並み**が欲しい → まず「写真AC」で `検索キーワード(日)` を使用
- **おしゃれな抽象・俯瞰・小物**が欲しい → Unsplash / Pexels で `検索キーワード(英)` を使用
- エリア記事は「東京 街並み」「tokyo cityscape」等で、特定できる看板・人物が写り込みすぎない画像を選ぶ

## 著作権・利用上の注意（重要）
- **商用利用可・クレジット不要**の素材を優先（上表）。各画像のライセンス表記は必ず確認。
- 人物の顔がはっきり写る画像は、モデルリリース済みのフリー素材サイトのものを使う。
- ロゴ・商標・実在の店舗名・他社物件が特定できる画像は避ける。
- 「無料」と書かれていても**帰属表示が必須**のサイト/画像があります。記事では帰属表示を入れにくいため、帰属不要のものを選ぶと安全です。
- 医療（クリニック記事）・金融（ローン記事）など、誤認を招く演出は避ける。

## ファイル命名規則（メディアライブラリを整理するため）
- アイキャッチ: `記事番号-スラッグ-hero.jpg`（例: `001-chuko-mansion-kounyu-nagare-hero.jpg`）
- 本文中: `記事番号-スラッグ-01.jpg` / `-02.jpg` …
- 形式は `.jpg`（写真）を基本に、図解は `.png` でも可。
- アップロード前に**横1200〜1600px程度**にリサイズし、ファイルサイズを圧縮（表示速度・SEOのため）。

## 作業フロー（1記事あたり）
1. `articles_image_brief.csv` の行を開く
2. `検索キーワード(日)`（または英）でフリー素材サイトを検索
3. 商用利用可・クレジット不要の画像を選んでダウンロード
4. `アイキャッチ_ファイル名` にリネーム（必要ならリサイズ・圧縮）
5. WordPress管理画面 **メディア > 新規追加** でアップロード
6. メディアの **代替テキスト（alt）** に `アイキャッチ_alt` を貼り付け
7. 記事編集時、アイキャッチに設定＋本文の見出し付近に画像を挿入

## alt（代替テキスト）について
- `アイキャッチ_alt` 列は、各記事の内容に沿った説明文をすでに用意しています。
- altは画像の内容を表す説明にし、キーワードの詰め込みは避けます（SEOチェックリスト #60 準拠）。

## ブリーフCSVを作り直すとき
記事を追加・修正したら、次でブリーフを再生成できます。
```bash
cd agents/content_creator/blog_factory
python3 generate_image_brief.py   # articles_image_brief.csv を更新
```

## ② フリー素材 一括ダウンロード（`download_images.py`）
`articles_image_brief.csv` のキーワード・ファイル名を使い、Pexels / Pixabay から
画像を一括ダウンロードします。**画像のはめ込み（記事への挿入）は手動**で行ってください。

### 事前準備：無料APIキーの取得（数分・無料）
- **Pexels**: https://www.pexels.com/api/ でアカウント作成 → API Key を発行
- **Pixabay**: https://pixabay.com/api/docs/ でアカウント作成 → API Key を確認
- どちらも**無料**・画像は商用利用可・クレジット不要（レート制限あり）。

### 実行手順
```bash
cd agents/content_creator/blog_factory

# 1) APIキーを環境変数にセット（ハードコード禁止。この値はコミットされません）
export PEXELS_API_KEY=あなたのキー        # Pexelsを使う場合
#   または
export PIXABAY_API_KEY=あなたのキー       # Pixabayを使う場合

# 2) ダウンロード実行（アイキャッチ1枚/記事・英語KWで検索）
python3 download_images.py --source pexels

# よく使うオプション
python3 download_images.py --source pixabay --per-article 2   # 1記事2枚（hero + -01）
python3 download_images.py --source pexels  --lang ja         # 日本語KWで検索
python3 download_images.py --source pexels  --only 001,002    # 指定記事だけ
python3 download_images.py --source pexels  --sleep 2.0       # レート制限がきつい時は待機を長く
```

### 出力
- 画像は `images/` に、`記事番号-スラッグ-hero.jpg`（必要なら `-01.jpg`…）で保存。
- 再実行しても既存ファイルはスキップ（途中から再開OK。`--overwrite` で上書き）。
- `images/_download_log.csv` に「ファイル名・検索語・ソース・撮影者・元URL」を記録。
- `images/` フォルダと `.env` は `.gitignore` 済み（バイナリ・キーはリポジトリに残りません）。

### ダウンロード後の流れ（手動）
1. `images/` の画像を確認し、人物・ロゴが目立つ等で不適切なものは差し替え（再検索/別サイト）
2. 必要なら横1200〜1600pxにリサイズ・圧縮
3. WordPress「メディア > 新規追加」でアップロード → alt に `アイキャッチ_alt` を設定
4. 記事編集で本文の見出し付近に挿入（はめ込みは手動）

> ヒント：英語KWでヒットが弱い記事は `--lang ja`（Pixabayが日本語に強め）や、
> `articles_image_brief.csv` の検索語を編集してから再実行すると精度が上がります。

## ③ WordPress 一括アップロード（オプション・未着手）
WordPressのアプリケーションパスワード＋サイトURLがあれば、`images/` をメディアへ
一括投入し alt も自動設定するスクリプトも用意できます。必要になったらお知らせください。
