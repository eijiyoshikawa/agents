対象: アークホーム（東京・首都圏）ブログ第2弾。既存150（No.1〜150）と**重複しない**新テーマ。
方針: **ローカルSEO重視**＝首都圏の市区町村・沿線・ペルソナ別を中心に90本＋売買/ローン/相続税の実務深掘り60本。

## 共通仕様（全記事）
- 出力先: `articles_local/<id>-<slug>.md`（YAML front-matter＋本文Markdown）
- front-matter: `id / category / title / subtitle / slug / target_keyword / sub_keywords / meta_description / tags / area:"東京・首都圏" / company:"アークホーム" / status:"draft"`
  - ※このシートはアイキャッチ不要のため **caption は不要**
- 本文: **2,500〜3,000字（空白・改行除く）**
- 構成: リード文（末尾に「**この記事でわかること**」＋箇条書き3点）→ `##`(h2)4〜6個・各h2に`###`2〜3個 → `## よくある質問`（**Q.**/A.×3）→ `## まとめ`（要点＋CTA）
- **「関連記事」は付けない**（シート運用で削除されるため最初から不要）
- Markdown表を最低1つ。見出しは`##`から（`#`は書かない）
- トーン: 親しみやすさ＋専門的な信頼感。「いかがでしたか？」禁止。語尾の単調反復を避ける

### ローカル（エリア）記事の事実性ルール（重要）
- 家賃・価格の**具体的な数値は断定しない**。「〜万円台が目安」など概算・相対表現にとどめ、「2026年時点の一般的な目安。最新は要確認」と明示
- 特定の物件名・店舗名・施設名を断定的に挙げない（一般的な特徴として記載）
- 「〜という声もある」「傾向がある」等、事実の断定を避ける。ランキングは主観と明示
- 路線・大まかな位置関係など変わりにくい事実は記載可

### 法務・税・制度記事の事実性ルール
- 制度（相続登記義務化・各種特例・フラット35S等）は**概要レベル**で説明。要件・金額・期限の細部は「2026年時点の一般的な内容。最新の詳細は公式・専門家に確認」と明示し、断定を避ける
