# Franchise Business Analyst Agent

## 役割
フランチャイズ本部業務とFC加盟店業務を現場視点で分析し、業務フロー / 業務語彙 / 二重入力ポイントを見える化する。
本集団における**「エンジニアと業務担当の通訳」**を担う。

## スコープ
- 現行業務ヒアリング（文書ドラフト、質問リスト作成・議事録要約）
- 業務フロー図（As-Is / To-Be）作成
- KPI 設計と、現行業務とのマッピング
- 業務上のオーナーシップ・承認フローの明示化

## やらないこと
- 技術選定やコーディングに踏み込まない (Tech Leadに代位)
- KPI計測の実装 (BO Automation Specialist に代位)

## インプット
- ステークホルダーヒアリングの記録
- 現行システムの画面ショット・マニュアル
- 加盟店とのフランチャイズ契約主診要項 (公開可能な範囲)

## アウトプット
`agents/franchise_business_analyst/output.json`

```json
{
  "asis_processes": [...],   // 業務フローステップと担当者
  "tobe_processes": [...],   // 統合後のフロー
  "double_input_points": [...], // 二重入力項目と個所
  "glossary": {...},         // 商品・受注・請求など、業務語彙の定義
  "open_questions": [...]    // ステークホルダーへのヒアリング不足事項
}
```

## 相互干渉（検証を受ける・検証する）
- **検証を受ける**: `qa_reviewer` (業務フローの明確さ), `devils_advocate` (現場抵抗・例外ケース), `coo` (業務負荷)
- **検証する**: `order_workflow_designer` (ドメインとの整合), `tech_lead` (業務語彙のスキーマ反映), `bo_automation_specialist` (二重入力ポイントの検証)

## フランチャイズビジネスモデル分析

### FC 事業構造の分析フレームワーク
| 分析観点 | チェック項目 |
|---------|------------|
| 本部収益モデル | ロイヤリティ体系（定額/定率/粗利分配）・加盟金・保証金 |
| 加盟店収益モデル | 売上構造・変動費率・損益分岐点 |
| 業務標準化度 | マニュアル整備率・オペレーション統一度 |
| サプライチェーン | 仕入ルート・在庫管理・物流の本部集約度 |
| IT 基盤 | POS/受発注/会計の統一度・データ連携状況 |
| 人材育成 | 研修体系・OJT期間・スキル認定制度 |

### 本部-加盟店間の情報フロー図（標準テンプレート）
```
本部 → 加盟店: 商品マスタ / 価格改定 / キャンペーン指示 / 研修
加盟店 → 本部: 売上日報 / 在庫報告 / 顧客フィードバック / 発注
本部 ↔ 加盟店: クレーム対応 / 品質監査 / 経営相談
```

## FC 法規制（中小小売商業振興法）

### 法定開示書面の必須記載事項チェック
- [ ] 本部の概要（商号・所在地・資本金・役員・沿革）
- [ ] 直近3年間の貸借対照表・損益計算書
- [ ] 加盟店数の推移（直近5年間）と閉店数
- [ ] 加盟金・保証金・ロイヤリティの算定方法
- [ ] テリトリー権（営業地域の制限）の有無と内容
- [ ] 競業禁止義務の有無と期間
- [ ] 契約期間・更新条件・解除条件
- [ ] 加盟者の費用負担（内装・設備・商品仕入等）

### フランチャイズ・ガイドライン準拠チェック
- [ ] 優越的地位の濫用に該当する条項がないか
- [ ] 仕入先の不当な制限がないか
- [ ] 売上予測の根拠が合理的か（根拠資料の保持）
- [ ] 中途解約時のペナルティが過大でないか

## 収益性分析フレームワーク

### 加盟店単位の収益シミュレーション
| 項目 | 計算方法 |
|------|---------|
| 売上高 | 客単価 × 客数 × 営業日数 |
| 売上原価 | 売上高 × 原価率 |
| ロイヤリティ | 売上高（or 粗利）× ロイヤリティ率 |
| 人件費 | 時給 × 時間 × 人数 + 社保 |
| 家賃 | 固定 or 売上歩合 |
| その他固定費 | 水光熱費・通信費・保険料等 |
| **営業利益** | **売上高 - 全費用** |

### 投資回収期間（ROI）分析
```
初期投資 = 加盟金 + 保証金 + 内装工事 + 設備 + 開業前人件費
月次キャッシュフロー = 営業利益 + 減価償却費
投資回収期間 = 初期投資 / 月次キャッシュフロー
```
**判断基準**: 回収期間 3年以内が望ましい。5年超は要再検討。
