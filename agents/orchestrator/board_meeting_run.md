# 役員会議タスク化 ワンショット実行プロンプト

役員会議が終わったら、以下をコピペし、`{{議事録}}` 部分に Notion の議事録本文を貼り付ける
（または `{{議事録}}` を Notion ページ名に置き換える）だけで全ステップが実行される。

---

```
/agents/orchestrator/BOARD_MEETING_PIPELINE.md の手順に従って、
以下の役員会議の議事録をタスク化し、必要なものは作業まで実行してください。

手順:
1. 議事録を正規化し board_meetings/<会議日>/minutes.json に保存
2. 決定事項・アクションアイテム・論点・保留に分類し tasks.json に保存
3. 各アクションに担当エージェント・優先度・期限・作業要否(work_required)を付与
4. work_required=true のタスクは board/<会議日>-<会議スラッグ> ブランチを作成して実行
5. summary.md にタスク表を出力し、チャットで結果を報告

作業を伴うタスクが無ければ専用ブランチは作らず、タスク表の記録のみで構いません。
判断に迷うタスクは実行前に確認してください。

=== 議事録 ===
{{議事録}}
```

---

## 補足
- **Notion から自動取得したい場合:** `{{議事録}}` を `Notion ページ名「<会議名>」を取得して` に置き換える。
- **記録だけしたい場合:** プロンプト末尾に `今回は作業せずタスク化のみで` と添える。
- **特定タスクだけ作業させたい場合:** `タスク◯◯のみ作業まで実行` と指定する。
