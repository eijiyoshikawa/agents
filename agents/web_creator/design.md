# Google Stitch デザインワークフロー

## Google Stitch とは
Google Labs が提供するAIネイティブUIデザインツール。
自然言語からハイフィデリティなUIを生成し、複数フレームワークへのコードエクスポートが可能。
Googleアカウントがあれば無料で利用できる。

- 公式サイト: stitch.withgoogle.com

## 主要機能（2026年3月アップデート対応）

### マルチスクリーン生成
- 自然言語でアプリ/サイト全体のフローを記述すると、最大5画面を同時生成
- 統一されたデザインシステム（タイポグラフィ・カラーパレット・コンポーネント）を自動適用

### AIネイティブキャンバス
- 無限キャンバス上でアイデア探索
- 画像・テキスト・コードの自由配置
- デザインエージェントによる進捗トラッキング

### Voice Canvas
- 音声コマンドによるリアルタイムデザイン指示・クリティーク

### モデル選択
- **Gemini 2.5 Pro**: 本番品質の洗練されたデザイン出力
- **Gemini 2.5 Flash**: 高速イテレーション・探索向け

### コードエクスポート
対応フォーマット:
- HTML / CSS
- Tailwind CSS
- Vue.js コンポーネント
- Angular テンプレート
- Flutter ウィジェット
- SwiftUI ビュー

### 外部連携
- **Figma エクスポート**: Auto Layout・命名済みレイヤー・編集可能テキスト付き
- **MCP サーバー**: コーディングエージェントとの直接接続

## デザインワークフロー

### Phase 1: プロンプト設計（要件 → Stitch プロンプト変換）

サイト要件を Stitch 用の自然言語プロンプトに変換する。

#### プロンプトテンプレート

```
【サイト種別】{site_type} のWebサイト
【ページ】{page_name}
【目的】{purpose}
【ターゲット】{target_users}
【デザインテイスト】{design_tone}
【カラー】{primary_color}, {secondary_color}, {accent_color}
【必須要素】
- {element_1}
- {element_2}
- {element_3}
【参考】{reference_sites}
```

#### LP（ランディングページ）の場合の例

```
不動産テック企業のランディングページを作成してください。

構成:
1. ヒーローセクション - キャッチコピー「AIで変わる不動産管理」、CTAボタン「無料相談」
2. 課題提起セクション - 不動産業界の3つの課題をアイコン付きで
3. サービス紹介 - 3つの主要機能をカード形式で
4. 導入実績 - 数字で示す成果（導入社数、業務削減率等）
5. お客様の声 - 3件のテスティモニアル
6. 料金プラン - 3段階の料金テーブル
7. FAQ - アコーディオン形式で5問
8. CTA - 最終コンバージョンセクション
9. フッター - 会社情報、リンク

デザイン: モダンでクリーン、信頼感のあるブルー基調
レスポンシブ: モバイルファースト
```

### Phase 2: Stitch でのデザイン生成・反復

#### Step 1: 初回生成
1. Stitch にプロンプトを入力
2. モデル選択: 探索段階では **Flash**、最終版では **Pro** を使用
3. マルチスクリーン生成で主要ページを一括作成

#### Step 2: デザインレビュー・改善
以下の観点で確認し、自然言語で修正指示を出す:

| チェック項目 | 確認内容 |
|------------|---------|
| ブランド整合性 | カラー・フォント・トーンがブランドガイドラインに合致するか |
| 情報階層 | 重要情報が視覚的に優先されているか |
| CTA配置 | コンバージョンポイントが適切に配置されているか |
| 余白・バランス | セクション間の余白、要素のバランスは適切か |
| レスポンシブ | モバイル表示での可読性・操作性 |

#### Step 3: 反復改善（2-3回）
- クライアントフィードバックを反映
- 細部の調整（色味、フォントサイズ、間隔等）
- 最終版は **Gemini 2.5 Pro** モデルで生成

### Phase 3: エクスポートと実装

#### 推奨エクスポートフロー

```
Stitch デザイン完成
    │
    ├─→ [推奨] HTML + Tailwind CSS エクスポート
    │       → Claude Code で実装・カスタマイズ
    │
    ├─→ [オプション] Figma エクスポート
    │       → デザイナーによる微調整 → 実装
    │
    └─→ [高度] MCP サーバー連携
            → コーディングエージェントで自動実装
```

#### Tailwind CSS エクスポート後の作業

1. **セマンティックHTML化**: Stitch出力のdivをsection, article, nav等に置換
2. **アクセシビリティ強化**:
   - 画像にalt属性を追加
   - フォーム要素にlabel/aria属性を付与
   - キーボードナビゲーション確認
   - コントラスト比 WCAG AA 準拠
3. **レスポンシブ調整**: ブレークポイントの微調整（sm/md/lg/xl）
4. **パフォーマンス最適化**:
   - 画像の最適化（WebP変換、lazy loading）
   - 不要なCSS削除
   - Core Web Vitals 確認（LCP, FID, CLS）
5. **インタラクション追加**: ハンバーガーメニュー、スムーズスクロール、アニメーション等

### Phase 4: 品質保証

#### チェックリスト

- [ ] 全ページのレスポンシブ表示確認（モバイル / タブレット / デスクトップ）
- [ ] クロスブラウザ確認（Chrome, Safari, Firefox, Edge）
- [ ] リンク・ボタンの動作確認
- [ ] フォームの送信テスト
- [ ] ページ速度テスト（Lighthouse スコア 90+）
- [ ] SEO基本要素（title, meta description, OGP, 構造化データ）
- [ ] アクセシビリティチェック（WAVE ツール等）
- [ ] ファビコン・OGP画像の設定

## サイト種別ごとのプロンプトガイド

### LP（ランディングページ）
重視ポイント: CTAの目立ち、ファーストビューのインパクト、ストーリー構成
```
[業種]の[目的]LP。ファーストビューにキャッチコピーとCTAを大きく配置。
スクロールで課題→解決策→実績→CTAの流れ。[色]基調でモダンなデザイン。
```

### コーポレートサイト
重視ポイント: 信頼感、情報の整理、採用ページ
```
[業種]のコーポレートサイト。トップ/会社概要/事業内容/採用/お知らせ/お問い合わせ。
信頼感のある落ち着いたデザイン。ニュース一覧はカード形式。
```

### サービスサイト
重視ポイント: 機能訴求、料金比較、導入フロー
```
[サービス名]のSaaS紹介サイト。ヒーロー/機能一覧/料金/導入事例/FAQ/CTA。
テック感のあるデザインで、機能はアイコン付きカードで説明。
```

### ECサイト
重視ポイント: 商品カタログ、カート導線、信頼バッジ
```
[商品カテゴリ]のECサイト。商品一覧/商品詳細/カート/決済フロー。
商品写真を大きく見せ、購入ボタンは常にアクセスしやすい位置に。
```

## 注意事項

1. **Stitch の出力はあくまで出発点** — そのまま納品せず、必ずコード品質・アクセシビリティの改善を行う
2. **ブランドガイドラインを優先** — Stitch のデフォルトスタイルよりクライアントのブランドを尊重
3. **日本語フォント対応** — Noto Sans JP / M PLUS 等、Google Fonts の日本語フォントを指定する
4. **法的要件** — プライバシーポリシー、特商法表記等の必須ページを忘れない
5. **画像素材** — Stitch生成のプレースホルダーは実際の素材に差し替える
