# Subsidy Writer Templates

補助金ごとの申請書様式テンプレートの保管場所。

## ディレクトリ規約

```
templates/
├── {subsidy_id}/
│   ├── application_form.docx    # 申請書本体（Word 原本）
│   ├── budget.xlsx              # 経費内訳（Excel 原本）
│   ├── README.md                # プレースホルダ・文字数制限・記載ルール
│   └── samples/                 # 過去採択事例のサンプル（権利関係に注意）
```

## プレースホルダ記述ルール

各 `{subsidy_id}/README.md` に以下を記載する:

| 項目 | 記載例 |
|------|--------|
| セクション名 | 事業概要 |
| プレースホルダキー | `{{business_overview}}` |
| 文字数上限 | 800文字 |
| 必須 / 任意 | 必須 |
| 評価観点 | 加点項目: 賃上げ・DX推進 |
| 補足 | 数値は直近3期分を記載 |

## 運用上の注意

- **著作権**: 公式事務局が配布するテンプレートは原則そのまま使用。再配布に制限がある場合は URL 参照のみとする。
- **改変禁止**: 様式のフォーマット・記載欄の順序は変更しない。
- **バージョン管理**: 補助金の年度更新時に `application_form_YYYY.docx` 形式でバージョン保存する。
- **PDF のみの様式**: OCR 読取り後のテキストを `README.md` にプレースホルダ定義として書き起こす（本文生成は Markdown → PDF 変換で対応）。

## 初期配置タスク

利用開始時に以下を配置する:
1. `it2026-general/` — IT導入補助金2026 通常枠
2. `monozukuri/` — ものづくり補助金
3. `jizokuka/` — 小規模事業者持続化補助金

テンプレート本体は公式事務局の配布ページから取得し、`README.md` にプレースホルダ一覧を記述する。
