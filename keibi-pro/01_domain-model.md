# 01. ドメインモデル

警備Pro の主要エンティティと属性。参考元の各マスタ画面・トランザクション画面から抽出。
新リポジトリでの DB スキーマ / API モデル設計の出発点とする。

> 凡例:🔑 = 主キー/識別子、→ = 参照(外部キー)、※ = 業務上の要点

---

## エンティティ関連(ER 概略)

```
自社 ─< 支店 ─< 担当者
                  │
得意先 ─< 配置先(現場) ─< 受注明細(日別必要人数)
   │          │
   │          └─< 請求単価(勤務種別×項目)
   │
   └─< 請求(締め単位) ─< 請求明細 ─ 入金消込

隊員 ─< 給与単価/スポット単価(勤務種別×項目)
  │
  ├─ 社会保険設定 / 住民税 / 固定支給 / 固定控除 / 資格手当 / 有給設定
  ├─< 同配置NG(隊員↔隊員)
  └─< クレーム履歴

勤務実績 ─ (得意先・配置先・隊員・勤務・日付) を結ぶ中心トランザクション
   ├─▶ 請求集計
   └─▶ 給与集計

勤務(勤務種別マスタ) ── 受注・配置・実績・単価の全てが参照
```

## 1. 組織系マスタ

### 自社 / 支店 / 担当者 / 担当者権限
- **自社**:会社名・住所・登録番号(インボイスT番号)・振込先口座(複数)・請求書ヘッダ情報。
- **支店**:🔑支店コード(例 `01 本社`)。全トランザクションは支店スコープ。
- **担当者**:営業担当者・現場監督等。
- **担当者権限**:画面/機能ごとのアクセス制御(ロール)。
- **金融機関マスタ / 郵便番号マスタ**:入力補助・住所/口座バリデーション。
- **祝日設定マスタ / 天候マスタ**:勤務日種別判定・日報の天候記録。

### 3-1. 請求単価設定(配置先 × 勤務種別 × 項目)
配置先ごとに、**勤務種別**(後述)別に下記項目の請求単価を保持するマトリクス。

- 単価(基本)/ 残業 / 昼残 / 早出 / 遅刻 / 時給 / 深夜 / 深夜残業
- ※「時間外単価・時給単価は1時間あたりの金額」を設定。

例(勤務種別):`001 日勤 / 002 資日勤 / 003 日祝 / 004 日資格祝 / 101 夜勤 / 102 資夜勤 / 103 夜祝 / 104 夜資格祝 / 201 早番 …`

### 3-2. 固定追加請求 / CTI / 機械学習 / 対応履歴(タブ)
配置先カードには上記の他、固定追加請求・対応履歴・CTI連携・(参考元の)機械学習タブが存在。新サービスでは「定例追加請求」「対応履歴(コール/メモ)」として再設計。

## 4. 隊員(警備員。給与・勤怠・配置の主役)

参考元:隊員マスタ `MST_1110`(タブ構成が多い = リッチなエンティティ)

### 4-0. 基本情報
| 属性 | 備考 |
|------|------|
| 🔑隊員番号 | 6桁(例 `000001`) |
| → 支店 | |
| 氏名 / フリガナ / 性別 | |
| 区分フラグ:外注 / 社員 / 非警備員 | 協力会社(法人)も隊員として登録され得る |
| → 隊員区分 | 例 `01 通常隊員 / 02 1級資格保持者` |
| 住所 / 電話 / その他TEL / メール / FAX | その他TELは教育Pro名簿の携帯欄に反映 |
| 緊急連絡先(氏名・続柄・住所・電話) | |
| 入社年月日 / 退社年月日 / 退社フラグ | |
| 入社前経験年数 / 経験年数 | 名簿の経験年数計算 |
| 資格等(自由記述欄) / 距離計算 | |

### 4-1. 給与(タブ)
- 給与形態:月給 / 日給・月給 / 週給
- 配偶者あり / 雇用保険加入 / 社会保険加入 / 時給自動計算
- 所得税区分(例「月額(甲)」)/ 扶養親族等(配偶者含む人数)
- 月給 / 遅刻単価(/1H)
- 精勤手当(Nカウント以上で X円)
- 隊員単価ランク(例 `9000`)
- **スポット単価設定**(勤務種別 × 単価・時間外単価・時給単価・深夜単価・深夜残業単価 + 手当1/手当2…)
  - 例:`001 日勤` に 手当1=交通費600・手当2=運転手当

### 4-2. 振込情報・備考(タブ)
- 支払方法:現金払い / 銀行振込 / 郵便局振込
- 銀行コード・支店コード・口座番号・口座種別(普通/当座)・口座名義人・記号番号
- 振込手数料(隊員負担フラグ)/ 振込情報の枠(給与振込①…)
- 日払サービス利用 / 給与明細住所非表示

### 4-3. 住民税 / 固定支給 / 固定控除(タブ)
- 住民税:6月〜翌5月の月別金額(一括セット可)
- 固定支給:交通費 / 特別勤務手当 / その他 …(コード+金額)
- 固定控除:制服代 / 仮払い …(コード+金額)
- 各「勤務実績が存在しない場合は集計しない」オプション

### 4-4. 資格手当設定(タブ)
- 資格手当(資格コード + 金額。例 098その他=50 / 099その他非課税=100)
- 資格保持(交通誘導警備1級/2級・普通自動車・2種運転免許 等 + 「免許欄印字」フラグ)

### 4-5. 社会保険設定(タブ)
- 保険料対象報酬額(4〜6月給料平均)→「社会保険料計算」で各保険料を自動算出
- 一般保険料等 / 健康保険 / 子育て支援 / 厚生年金 / 介護保険(40歳以上対象)
- 健康保険番号・名称(協会けんぽ/組合)/ 年金保険名称(厚生年金 等)
- 年金受給者区分 / 雇用保険区分(一般/日雇/適用除外)/ 雇用保険番号
- 建退共手帳の有無 / 高齢任意加入

### 4-6. クレーム(タブ)
- 日付・得意先・配置先・**再配置区分**・クレーム内容を履歴管理
- 再配置区分:**可 / 注意 / 不可 / 得意先不可** → 配置(シフト)時の判断材料

### 4-7. 同配置NG(タブ)
- 一緒に配置してはいけない隊員の登録(支店・隊員・備考)
- 例「樋口一葉/夏目漱石(仲が良くない)/内勤内子」
- → 配置予定入力時に**NG警告ダイアログ**を出すための制約データ

### 4-8. 有給設定(タブ)
- 有給付与基準日 / 前回付与日 / 有給計算開始日
- 給与明細書に有給情報を記載するフラグ
- 有給付与単位:対象外 / 日数単位 / 月単位 / 所定労働日数8割判定

## 5. 勤務(勤務種別マスタ)・勤務グループ・警備業区分・資格

- **勤務(種別)**:`001 日勤`, `101 夜勤`, `701 ビル昼`, `703 F病院昼` 等。基本時間帯(例 08:00〜17:00 / 22:00〜05:00)を保持。受注・配置・実績・請求単価・給与単価の**共通キー**。
- **勤務グループ**:帳票印刷時の集計グルーピング(印刷結果にのみ反映)。
- **警備業区分**:1号(施設)/2号(交通誘導・雑踏)/3号(輸送)/4号(身辺)等。契約書様式の出し分けにも影響(1号警備契約書 / 2号警備契約書)。
- **資格マスタ**:交通誘導警備1級/2級、普通自動車、2種運転免許 等。隊員資格・資格手当・名簿の免許欄に連動。
- **隊員区分マスタ**:通常隊員 / 1級資格保持者 等。名簿絞り込み・単価ランクに関係。

## 6. トランザクション

### 6-1. 受注明細(受注入力 `DPI_4090`)
- キー:支店・日付・得意先・配置先・勤務 × 1〜31日
- 値:日別の必要人数
- 集計:日勤計 / 夜勤計 / 受注計 / 稼働可能数 / 休日隊員数

### 6-2. 配置(配置予定入力 `DPI_4100`)
- キー:日付・支店・配置先・勤務
- 値:割り当てた隊員(複数)
- ステータス色分け:**未配置(黄)/ 配置済(白)/ 配置連絡済(水)/ 出発報告済(緑)/ 下番未確認(赤)/ 実績(灰)**
- 制約:同配置NG・休日(休/△交渉可能)・資格・得意先不可

### 6-3. 勤務実績(勤務実績入力 `DPI_4010`)← 中心トランザクション
1行 = 1日 × 1隊員 × 1配置先 × 1勤務。主な列:

- 得意先 / 配置先 / 隊員 / 業務内容(勤務種別)
- 基本時間 / 報告時間(実働)
- 請求% / 給与% / 休憩 / 深休 / 早出 / 昼残 / 残業 / 遅早
- 無線台数 / 無線セット / 返却 / 距離 / 規制車 / 高速代 / 交通費 / 課税交通費 / 燃料代 / 前月度差額分 / 資機材 / 熱中症対策費 / 運転手当 / 資格手当
- 実H(実働時間)/ 請求H / 給与H / 日払

**単価の二層構造**:各実績行は、マスタ単価(配置先=請求 / 隊員=給与)を既定値としつつ、当日実績で個別オーバーライド可能(`DPI_4080` 単価情報 / `DPI_4081` 単価一括更新)。
※「単価を0にするとマスタ単価を優先集計。0円集計したい場合はマスタ側で変更」。

### 6-4. 請求(請求集計 `DPI_5010` / 請求入力 `DPI_5011`)
- 締め(締日締め)で勤務実績→請求データに集計
- 請求ヘッダ:請求金額・値引き・追加請求計・小計・消費税・追加非課税・請求合計
- **追加請求**(日付・名称・個数・単価・税率・金額。例:資機材、スポット項目)
- 締め/集計ステータス、消費税率(軽減税率対応 ※)

### 6-5. 入金(入金一覧入力 `DPI_6040`)
- 入金予定日 / 得意先 / 請求額 / 入金日 / 入金額 / 手数料 / 安全会費 / 調整額 / 入金合計 / 差引金額 / 集計年月
- 請求額=入金合計で青字(消込完了)、差引金額で売掛残を可視化

### 6-6. 給与(給与集計 `DPI_7020` / 給与入力 `DPI_7021`)
- 締め期間(例 04/21〜05/20)で勤務実績→給与データに集計
- 支払合計(基本給・残業・遅刻・小計・精勤手当・各種手当)
- 控除合計(所得税・健康保険・厚生年金・雇用保険・介護保険・住民税・固定控除)
- 支給合計 / 課税対象額 / 控除合計 / **差引支払額**
- 集計オプション:全再計算 / 住民税計算 / 社会保険計算 / 固定支給・控除集計 / 年調PRO還付金取込 / 有給計算
