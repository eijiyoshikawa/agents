# 05. 業務ルール・計算ロジック

警備Pro のドメインで特に注意すべき計算・制約。新サービスの仕様化・テスト設計の基礎。

---

## 1. 単価の二層構造(請求・給与)

各勤務実績行は、**マスタ単価を既定値**としつつ、**実績行で個別オーバーライド**できる。

```
請求単価:配置先マスタ(現場 × 勤務種別 × 項目) ── 既定 ──┐
                                                          ├─▶ 勤務実績行(変更単価) ─▶ 請求集計
給与単価:隊員マスタ(隊員 × 勤務種別 × 項目)   ── 既定 ──┘                          ─▶ 給与集計
```

- 項目(請求):単価 / 残業 / 昼残 / 早出 / 遅刻 / 時給 / 深夜 / 深夜残業
- 項目(給与):単価 / 時間外 / 時給 / 深夜 / 深夜残業 + 手当(交通費・運転手当 等)
- **「時間外単価・時給単価は1時間あたりの金額」**。
- **重要ルール:単価を 0 にするとマスタ単価を優先して集計する。**
  「0円で集計したい」場合はマスタ側で0に変更する必要がある(実績行の0=未設定=マスタ参照、の意味)。
- 一括更新:期間 × 支店 × 得意先 × 配置先 × 勤務 で請求単価、期間 × 支店 × 隊員 × 勤務 で給与単価をまとめて変更可能(`DPI_4081`)。

---

## 2. 勤務種別と時間帯

- 勤務種別は基本時間帯を持つ(例:`001 日勤`=09:00〜18:00 / 08:00〜17:00、`101 夜勤`=22:00〜05:00)。
- 資格者向け(`002 資日勤`, `102 資夜勤`)、祝日(`003 日祝`, `103 夜祝`)、資格祝(`004 日資格祝`)等のバリエーションがあり、それぞれ単価が異なる。
- 報告時間(実働)と基本時間の差分から残業・早出・遅刻・深夜等を算出。

---

## 3. 請求金額の構成

請求 = 基本(人数 × 単価)+ 残業/早出/深夜等の時間外 + 時給ベース + 無線機代 + 追加請求(資機材等)− 値引き
- 消費税:課税方法(外税/内税)・税率(10%/8%軽減)に従う。
- 端数処理:配置先設定(切捨/四捨五入/切上)。
- 追加非課税項目を別管理。

### 3-1. 月極 と スポット(★決定:両対応・現場ごとに選択)
配置先マスタの `rate_form` で切り替える。

| 形態 | 請求の作り方 | 備考 |
|------|------------|------|
| **月極(monthly)** | **契約月額を固定請求**(勤務実績の有無に関わらず基本額を立てる) | 施設警備・常駐等。契約人数・契約時間・月極単価を `sites.monthly_*` で保持。増減・欠勤控除は調整行で対応 |
| **スポット(spot)** | **勤務実績 × 単価で都度算出** | 交通誘導等の日次。実績がそのまま請求明細になる |

- 同一得意先内で現場ごとに月極/スポットが混在し得る → 請求書(得意先別)では両者を合算して表示。
- 月極でも追加請求(資機材・スポット応援等)は明細加算可能。

### 3-2. キャンセル料(★決定:現場ごとにルール設定→半自動)
スポット現場で、暴風雨等により工事中止になった場合のキャンセル料。契約書第10項を**設定値化**する。

- `sites`(または `contracts.terms`)に **キャンセル規定**を保持(例:2日前まで無料 / 前日17時前=50% / 前日17時以降=全額)。
- 運用:中止連絡の**日時を記録**すると、規定に照らして**キャンセル料(請求額)を提案** → 担当者が確認・確定(全自動にはしない=例外が多いため)。
- キャンセル料は請求明細(または追加請求)として計上。消費税の扱い(税込/税別)は規定に準拠。

## 4. 給与計算の構成

支給 = 基本給(出勤日数 × 日給単価 もしくは 月給)+ 時間外 + 深夜 + 精勤手当 + 固定支給(交通費・特別勤務手当 等)+ 資格手当 + その他手当
控除 = 所得税 + 健康保険 + 厚生年金 + 雇用保険 + 介護保険 + 住民税 + 固定控除(制服代・仮払い 等)
**差引支払額 = 支給合計 − 控除合計**

### 4-1. 精勤手当
- 「N カウント以上で X 円」(例:23 カウント以上で 10,000 円)。

### 4-2. 社会保険料
- 保険料対象報酬額 = 4・5・6月の給料平均。
- 健康保険・厚生年金・雇用保険・介護保険を自動算出。
- **介護保険は 40歳以上が対象**。
- 健康保険(協会けんぽ / 組合)・年金種別を隊員ごとに設定。
- 雇用保険区分:一般保険 / 日雇保険 / 適用除外。

### 4-3. 所得税
- 所得税区分(月額 甲/乙 等)・扶養親族等の人数(配偶者含む)で源泉税額を決定。

### 4-4. 住民税
- 6月〜翌5月の月別金額を隊員ごとに保持(特別徴収)。

### 4-5. 有給
- 付与単位:対象外 / 日数単位 / 月単位 / 所定労働日数8割判定。
- 付与基準日・前回付与日・計算開始日から付与日数を算出。給与明細に有給情報を記載可能。

## 5. 配置(シフト)制約

配置予定入力での隊員割当時に評価する制約:

| 制約 | 内容 | 挙動 |
|------|------|------|
| 同配置NG | 隊員Aと隊員Bを同一現場に入れない(隊員マスタ同配置NG) | 警告ダイアログ(配置する/キャンセル/詳細) |
| 休日 | 隊員が休日(休)/ 交渉可能(△) | 休日フィルタ・交渉可否表示 |
| ダブルブッキング | 同日同時間帯に別現場へ既配置 | 隊員検索で赤字+配置先名表示 |
| 資格要件 | 現場が要求する資格(交通誘導2級 等) | 資格フィルタ |
| クレーム再配置区分 | 可 / 注意 / 不可 / 得意先不可 | 該当得意先・現場への再配置可否判定 |
| 必要人数充足 | 受注必要人数 vs 配置済 | 未配置カウンタ(0が目標) |

### 配置ステータス遷移
```
未配置(黄) → 配置済(白) → 配置連絡済(水) → 出発報告済(緑) → [下番未確認(赤)] → 実績(灰)
```

## 6. 締め・サイクル

- 締日・請求日・入金予定日は**配置先(現場)単位**で設定(例:20日締め / 請求 0ヶ月後31日 / 入金 1ヶ月後25日)。
- 請求集計・給与集計はそれぞれ締め期間で実績を確定。**集計済ステータス**を持ち、再集計フローを用意。
- 入金消込:請求額 = 入金合計 で消込完了(青字表示)。差引金額で売掛残を管理。

---

## 7. 区分・属性の取りうる値(列挙)

- **請求形態**:月極 / スポット
- **給与形態**:月給 / 日給・月給 / 週給
- **支払方法(隊員)**:現金払い / 銀行振込 / 郵便局振込
- **口座種別**:普通 / 当座
- **課税方法**:外税 / 内税
- **端数処理**:切捨 / 四捨五入 / 切上
- **再配置区分**:可 / 注意 / 不可 / 得意先不可
- **雇用保険区分**:一般保険 / 日雇保険 / 適用除外
- **有給付与単位**:対象外 / 日数単位 / 月単位 / 所定労働日数8割判定
- **隊員フラグ**:外注 / 社員 / 非警備員
- **警備業区分**:1号(施設)/ 2号(交通誘導・雑踏)/ 3号(輸送)/ 4号(身辺)

---

## 8. テスト観点(抜粋)

- 実績単価0 → マスタ単価で集計されること。
- 同配置NG隊員を同一現場に配置 → 警告が出ること。
- 締め後の実績変更 → 再集計で請求/給与が更新されること。
- 介護保険:40歳未満は0、40歳以上で計上。
- 端数処理・外税/内税の組合せで請求合計が一致すること。
- インボイス:税率別の区分記載・登録番号印字。
- 月またぎの夜勤(22:00〜翌05:00)の深夜時間・実働Hの按分。
