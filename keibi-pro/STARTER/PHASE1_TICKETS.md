# Phase 1 実装チケット一覧(issue化用)

**ゴール:受注 → 配置 → 勤務実績 → 請求集計 → 請求書PDF → 入金消込 が1本通る + モバイル日報。**
各チケットはそのまま GitHub Issue 化できる粒度。`docs/` = 旧 `keibi-pro/`。

凡例:`[P0]`最優先 / `[P1]`次 / `[P2]`後 ・ `est` 目安(S=〜1d, M=2-3d, L=1w) ・ `dep` 依存

ラベル例:`epic:*` `area:api` `area:ui` `area:mobile` `area:db` `type:feat` `type:test`

---
