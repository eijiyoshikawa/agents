## 1. 警備Pro(基幹)

- 勤務入力 → 給与・請求が連動して一元管理。残業・遅刻・早退は実績変更で自動計算。
- 請求:締め日にボタン一つで集計→請求書作成。締め日の臨時変更可。セット印刷(請求先ごと帳票設定)。表紙(鑑)+配置先別明細の構成が好評。
- 給与:締めでボタン一つ集計→給与明細。社保込み。内勤/外注は一括集計しない等のイレギュラー対応。
- 入金:入金予定/実績/不足/手数料/安全会費/調整額。得意先元帳。
- 帳票:**合計115帳票**。
- ⭐ **警備業特化機能**:
  - **仮払い管理**
  - **交通費の距離計算**
  - **資格者配置 路線検索機能**(検定合格警備員の配置義務に対応した路線・現場の検索)
  - 警備業特有の勤務体系に対応
- ⭐ **法定三帳簿**:労働者名簿・出勤簿・賃金台帳を簡単作成。

## 2. 管制Pro / スマホde勤怠・スマホdeサイン(モバイル)★最重要

我々の `08`(日報)・`09`(隊員アプリ)・`10`(UX)と直結。

### スマホde勤怠
- **お知らせ送信**:全体/個人/複数人へメッセージ。アプリ起動直後に表示で確認漏れ防止。配信状況をリアルタイム把握。通信費削減。
- **勤怠報告(上下番)**:ワンタップ報告 → リアルタイム反映 → **ワンクリックで警備Proへ取込**。上下番連絡対応の手間を削減。
- **シフト管理**:警備Proで管制入力 → ワンクリックでシフト送信 → 隊員はワンタップ確認 + **地図アプリで現場までナビ**。配置連絡の手間ゼロ、ペーパーレス。
- **休暇申請**:ペーパーレスで申請・承認。申請状況リアルタイム。
- **給与確認**:給与明細をスマホでいつでも確認。配布ミス等のリスク削減。

### スマホdeサイン(警備日報の電子化)⚠ 我々の前提と差分
- フロー:**日報選択 → 報告書にサイン(スマホ上で署名)→ クラウド保存 / 控えを自動送信**。
- ⚠ JBCAは**スマホ画面上で電子署名(紙не使用)**。我々の `08` は「**現場でサインをもらった紙を撮影**」前提。
  → **両対応**を推奨:(a) 端末上で電子サイン(ペーパーレス)、(b) 紙サインの写真アップロード(顧客が紙必須の場合)。
- ⭐ **取引先へ警備日報の控えを自動送信**(=請求エビデンス共有)。誤字脱字・破損・紛失リスク回避、交通費・郵送料削減。
- 別途システム利用料が必要(=オプション課金)。

### ⭐ 効果データ(ビジネスケースに使える)
- 50名規模で **作業時間 約76.8%削減(約65.2時間/月)**。
- 削減対象フロー:拠点ごとのタイムカード・日報回収 → システム転記 → ダブルチェック → 給与明細印刷・裁断・配布 を電子化。

## 3. 教育Pro(備付書類・教育管理)

我々の `04`(帳票)・教育管理(オプション)を強化。

- ⚠ **83.3%の警備会社が備付書類の作成で課題**(2024/4 アンケート)。→ 大きな痛点=機会。
- 機能:
  - **警備員名簿**(写真+情報をセット管理、検索可、立入資料としてそのまま印刷)
  - **従事する警備業務の内容**:管制データから引用(警備Pro連動)
  - **備付書類の作成**:教育実施内容を入力するだけで立入提出書類を作成
  - **教育状況の可視化**:新任/現任の教育状況、各隊員の書類提出状況をダッシュボードでリアルタイム
  - **指導監督管理 / クレーム管理 / 苦情管理 / 指導計画管理**
- 法改正に迅速対応。

## 5. JBCAアシスタントPro(AI)⭐ 差別化ヒント

- **自然言語クエリ**:「先月の粗利を教えて」「現場別の売上を集計して」→ AIが分析・回答(チャットUI、履歴あり)。
- **AI分析・集計**:売上・粗利・勤務実績を可視化(グラフ)。
- **データ出力**:隊員/現場/勤務実績/請求・給与をCSV・Excelで条件抽出。
- **カスタム出力 / カスタム帳票**:項目・並び・条件を自由設定、ドラッグ&ドロップで独自帳票(近日リリース)。**フォントサイズ指定**あり。
- 他システム連携。

→ 新サービスは **AI分析・自然言語クエリ・カスタム帳票を「最初から内蔵」**できれば強い差別化(JBCAは別製品=追加課金)。
