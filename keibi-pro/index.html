このデモの公開方法（Vercel）

このフォルダ（keibi-pro/）はビルド不要の静的サイトです。新リポジトリに置いてVercelに繋ぐだけで即公開できます。

  1. 新規リポジトリを作成し、keibi-pro/ の中身をリポジトリ直下にコピー（または Vercel の Root Directory を keibi-pro に設定）。
  2. Vercel で「New Project」→ 当リポジトリを Import。フレームワークは Other（静的）。
  3. Deploy → 公開URLの / でこのデモ、/sales/preview/lp.html でLPが開きます。

※ 詳細は DEPLOY.md。本番アプリ（Next.js+DB）は STARTER/ と docs/ を土台に構築します。
