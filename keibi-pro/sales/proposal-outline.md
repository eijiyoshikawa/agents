# 提案資料 構成案（警備Pro / 商談用スライド）

> 用途:商談・デモ後に置いてくる提案スライド（Google Slides / PowerPoint 想定）。
> デザインは別Claudeプロジェクト/別セッションで作成。本書は**ページ構成＋各ページの要点・話法**。
> 想定:15〜20ページ。意思決定者（経営者）＋実務者（管理部）同席を想定。

---

## ストーリーライン
「現状の負担 → 原因（バラバラ・手作業） → 解決（一元化） → 具体機能 → 効果（数字） → 安心（サポート/移行/セキュリティ） → 料金 → 次の一歩」

## 効果試算（ページ15の差し込み式）
- 入力:隊員数 N、月の事務作業時間 H、削減率 76.8%、事務時給 W。
- 試算:**削減時間 = H × 0.768**、**金額換算 = 削減時間 × W**。
- 例:H=85h、W=2,000円 → 約65h削減・約13万円/月（年156万円）相当。
> ※数値は前提明示の上で提示。自社/類似実績が出れば差し替え。
