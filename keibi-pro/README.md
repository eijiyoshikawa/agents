# 警備Pro — サービス座組・引き継ぎドキュメント

> 警備会社向けの統合業務管理サービス。
> **受注 → 配置(シフト)→ 勤務実績 → 請求 → 入金** と **勤務実績 → 給与** の2本の業務フローを、
> 得意先 / 現場(配置先)/ 隊員 のマスタ情報を起点に「1つのシステム」で一気通貫管理する。
> 既存パッケージ「JBCA警備Pro」(株式会社ビジコン・ジャパン)の業務領域を参考に、
> Webベースのモダンなサービスとして再設計する。

このディレクトリは、新リポジトリへ引き継ぐための **要件・座組ドキュメント一式** です。
コードは含みません。新リポジトリ作成時にこの内容を移植・肉付けして開発を開始します。

## このサービスは何を解決するか

警備会社のバックオフィスは、以下が**別々の台帳・Excel・紙**で管理されがちで、転記ミス・二重入力・締め作業の属人化が起きやすい。

- 得意先・現場・契約の管理
- 「今日どの現場に誰を何人配置するか」の日次シフト調整
- 警備員(隊員)の勤怠・実績収集
- 得意先への請求(現場ごとに単価・勤務種別が異なる)
- 入金消込・売掛管理
- 警備員の給与計算(日給/月給、社保・住民税・各種手当控除)
- 法定帳票(作業員名簿=全建統一様式第5号、1号/2号警備契約書 等)

**警備Pro は、これらをマスタ連携した1つのデータモデル上で完結させる。**
> 設計思想:「1つのシステムで管理することで転記ミスが激減し、社内のルール化が図れる」。

## 中核となる3つのマスタと2つのトランザクション

**マスタ(誰に・どこで・どう働くか)**
1. **得意先**(請求先の顧客)
2. **配置先 / 現場**(得意先配下の警備現場。請求単価・勤務種別・締め条件を保持)
3. **隊員**(警備員。給与単価・社保・資格・配置NG・有給を保持)

**トランザクション(2本の流れ)**
- **請求ライン**:受注 → 配置 → 勤務実績 → 請求集計 → 請求書 → 入金
- **給与ライン**:勤務実績 → 給与集計 → 給与明細 → 振込データ

両ラインの**結節点が「勤務実績(1日1隊員1現場の1行)」**。
ここに「請求単価」と「給与単価」の両方が紐づき、片方の実績入力から請求・給与の双方が自動集計される。これが本サービスの心臓部。
