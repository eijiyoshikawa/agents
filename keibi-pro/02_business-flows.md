# 02. 業務フロー

警備Pro の業務は **日次業務** と **月次業務** に分かれ、勤務実績を結節点に
「請求ライン」と「給与ライン」の2本が走る。

---

## 全体像

```
┌──────────────────────── 事前準備(マスタ整備)────────────────────────┐
│ 得意先・配置先(現場)・隊員・勤務種別・単価・契約を登録                  │
└──────────────────────────────────────────────────────────────────────┘
                                   │
┌────────────────────────── 日次業務 ──────────────────────────┐
│  ① 受注入力      現場×勤務×日 に必要人数を入力                  │
│       ▼                                                        │
│  ② 配置予定入力  必要人数枠へ隊員を割当(制約チェック付き)      │
│       ▼                                                        │
│  ③ 勤務実績入力  実際の勤務(時間・手当・交通費等)を確定        │
└────────────────────────────────────────────────────────────────┘
                                   │ 締め(締日)
        ┌──────────────────────────┴──────────────────────────┐
        ▼ 請求ライン(月次)                                     ▼ 給与ライン(月次)
┌─────────────────────────────┐                  ┌─────────────────────────────┐
│ ④ 請求集計(締め)            │                  │ ⑦ 手当・控除入力             │
│ ⑤ 請求入力(追加請求/調整)   │                  │ ⑧ 給与集計                   │
│ ⑥ 請求書印刷/PDF発行         │                  │ ⑨ 給与入力(明細確認・確定)  │
│       ▼                      │                  │ ⑩ 振込データ作成 / 給与明細   │
│   入金管理(消込・売掛)      │                  └─────────────────────────────┘
└─────────────────────────────┘
```

---

## 日次業務

### ① 受注入力(`DPI_4090`)
- 月の暦(1〜31日、曜日・祝日色分け)に対し、
  **得意先 × 配置先 × 勤務種別** の各行へ **日別必要人数** を入力。
- 例:モチベ/1交差点/日勤 → 平日4名・土日0名、夜勤2名…
- 画面下部で日勤計・夜勤計・受注計・稼働可能数・休日隊員数を自動集計。
- → 「この日この現場に何人必要か」という**需要(枠)**を確定する工程。

### ② 配置予定入力(`DPI_4100`)= シフト割当(本サービスの中核UX)
- 日付・支店を選び、左右2ペイン(日勤側 / 夜勤側)に
  **得意先・配置先・勤務・必要人数・割当済隊員** を表示。
- 必要人数枠(黄=未配置)に隊員を割り当てると白(配置済)に変わる。
- **ステータス色分け**で当日のオペレーションを可視化:
  | 色 | 状態 |
  |----|------|
  | 黄 | 未配置 |
  | 白 | 配置済 |
  | 水色 | 配置連絡済(隊員へ連絡完了) |
  | 緑 | 出発報告済 |
  | 赤 | 下番未確認(終業確認待ち) |
  | 灰 | 実績(実績確定済) |
- **隊員ピッカー(`HLP_4017`)**:資格・隊員区分・フリガナ・休日情報(休/△交渉可能)で絞り込み。配置済の隊員は赤字+現在の配置先名を表示し、ダブルブッキングを防止。協力会社(外注法人)も割当対象。
- **制約チェック**:
  - **同配置NG**:NG関係の隊員を同一現場に入れると警告ダイアログ(`DPI_4110`「同配置先にNG隊員が登録されています。配置しますか?」→ 配置する/キャンセル/詳細を見る)。
  - 休日・資格要件・クレーム再配置区分(可/注意/不可/得意先不可)を考慮。
- 下部に 隊員数 / 休日者 / 交渉可能者 / 出勤可能者 / 受注 / 配置済 / **未配置** のカウンタ。未配置を0にするのが配置担当のゴール。

### ③ 勤務実績入力(`DPI_4010`)
- 配置予定をベースに、**実際の勤務実績**を1行=1日1隊員1現場で確定。
- 報告時間(実働)・残業・深夜・早出・遅刻、交通費・運転手当・無線・資機材等の付帯項目を入力。
- 時間一括セット(報告時間/基本時間を選択行へ一括反映)等の効率化UI。
- 予定データ/実績データ/集計済データを切り替え、管制日報を出力。
- **この実績が請求・給与の双方の集計元**になる。
- 行ごとに請求単価・給与単価を確認/個別変更可能(`DPI_4080` 単価情報、`DPI_4081` 期間・現場・隊員単位の単価一括更新)。

## 月次業務 — 請求ライン

### ④ 請求集計(`DPI_5010`)
- 請求書月・締日(例 20日)・請求書範囲日付・支店・得意先・配置先で対象抽出。
- 配置先ごとに 消費税率・期間・締め/集計ステータス を一覧化。
- **締め集計(F7)** で勤務実績→請求データへ確定。全支店一括集計も可。

### ⑤ 請求入力(`DPI_5011`)
- 得意先×配置先別に請求明細を確認・微調整。
- 上部に請求合計(請求金額・▲値引き・追加請求計・小計・消費税・追加非課税・請求合計)。
- **追加請求**:資機材・スポット項目等を行追加(日付・名称・個数・単価・税率・金額)。
- 明細ダブルクリックで該当の勤務実績入力画面へジャンプ(トレーサビリティ)。
- 帳票オプション(住所有無・明細合算・勤務時間印刷・単価印刷・消費税欄印字)。
- 請求再集計 / 請求更新 / 請求書印刷 / 一括印刷 / PDF出力。

### ⑥ 請求書印刷(`PRN_5030`)
帳票バリエーション:
- 得意先別請求書(サマリ:配置先ごとの合計金額一覧)
- 月極得意先別請求書
- 得意先別配置先別請求書(サマリ+配置先ごとの日次明細)
- 得意先別請求明細書
- 得意先別請求一覧表

オプション:繰越印刷・宛先住所・明細合算しない・配置先選択印刷・消費税率表示・勤務時間印刷・単価印刷・入金区分別出力・自社印字・PDF出力。
**インボイス対応**(登録番号T〜、税率別表示、軽減税率※)。

### 入金管理(`DPI_6040` 入金一覧入力 / 入金入力 / 得意先元帳)
- 請求に対する入金を記録・消込。
- 入金予定日・請求額・入金日・入金額・手数料・安全会費・調整額・入金合計・差引金額。
- 請求額=入金合計 → 青字(消込完了)。差引金額で**売掛残**を管理。
- 得意先元帳で取引履歴・残高を確認。

## 月次業務 — 給与ライン

### ⑦ 手当・控除入力
- 勤務実績に紐づかない臨時の手当・控除を入力(実績入力からも `F3` で遷移可)。

### ⑧ 給与集計(`DPI_7020`)
- 支店・給与形態(月給/日給月給/週給)・締め期間(例 04/21〜05/20)・支払方法・隊員区分・隊員で対象抽出。
- **給与集計(F7)** で勤務実績→給与データへ確定。
- オプション:全再計算 / 住民税計算 / 社会保険計算 / 隊員マスタ固定支給・固定控除を集計 / 手当控除再集計しない / 年調PRO還付金取込 / 有給計算のみ実行 / 全支店一括。
- 漏れデータを含む給与には隊員名に「※」表示。

### ⑨ 給与入力(`DPI_7021`)
- 隊員別の給与明細を確認・確定。
- 支払:基本給(出勤日数×単価)・残業・遅刻・小計・精勤手当・各種手当(超過手当・交通費・特別勤務手当・運転手当 等)。
- 控除:所得税・健康保険・厚生年金・雇用保険・介護保険・住民税・固定控除(制服代・仮払い 等)。
- 支給合計 / 課税対象額 / 控除合計 / **差引支払額**。
- 所得税・社会保険再計算 / 給与明細再計算 / 給与更新 / 給与確定。
- 支払明細ダブルクリックで勤務実績へジャンプ。

### ⑩ 振込データ作成 / 給与明細書 / 賞与 / 年調
- 給与明細書印刷(明細/勤務明細付き)・給与一覧帳票。
- 全銀フォーマット等の**振込データ作成**。
- 賞与入力・賞与一覧入力。
- 年調Pro連携(年末調整・還付金取込)。

---

## モバイル/オプション

- **スマホde勤怠**:隊員がスマホで出退勤を入力 → 勤務実績へ連携。給与・賞与確定の一括登録。
- **スマホdeサイン**:電子サイン(契約・受領印 等)。
- **教育Pro**:警備員の法定教育管理(隊員名簿連携)。
- **管制Pro**:管制日報・現場連絡。

---

## 締め・サイクルの考え方(重要)

- **締日は配置先(現場)単位**で持つ(例 20日締め、翌月X日請求、翌々月Y日入金予定)。
- 請求の締め期間と給与の締め期間は別管理(例:請求 04/21〜05/20、給与 04/21〜05/20 だが基準が異なる場合あり)。
- 締め確定後の実績変更は再集計が必要。請求/給与とも「集計済」ステータスで管理し、再集計フローを用意する。
