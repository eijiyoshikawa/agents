# 04. 帳票・出力一覧

警備Pro が出力する帳票。法定様式・対外帳票・社内帳票に分類。
新サービスでは PDF 生成 + Excel/CSV エクスポートで実装する想定。

---

## 1. 対外帳票(得意先向け)

### 1-1. 御請求書(得意先別請求書 `RPT_503010`)
- ヘッダ:宛先(得意先・敬称)、自社情報、**インボイス登録番号 T+13桁**、複数振込先口座
- サマリ:請求月 / 請求金額(10%)/ 消費税(10%)/ 合計請求金額
- 明細:No / 請求期間 / **配置先名** / 合計金額(配置先ごとの集計行)
- 「下記の通りご請求申し上げます」+ 得意先マスタ請求書備考欄

### 1-2. 配置先別請求明細書(`RPT_502010`)
- 会社名 / 作業所名(配置先)/ 請求月 / 請求期間 / 請求金額・消費税・非課税額・合計
- 内訳明細:月日 / 実施形態(勤務種別)/ 人数・数量 / 基本金額 / 残業H・残業金額 / 時間 / 金額 / 合計金額 / 備考
- 軽減税率対象は ※ 表示
- 追加請求(資機材等)も明細行として印字

### 1-3. 得意先別配置先別請求書(`RPT_503030`)
- 1-1 のサマリ + 配置先ごとの日次明細(複数頁)。時給ベースの行(例 14.00/h 21,000)も表現。

### 1-4. その他請求帳票(`PRN_5030` から選択)
- 月極得意先別請求書 / 得意先別請求明細書 / 得意先別請求一覧表

## 2. 法定・準法定帳票

### 2-1. 作業員名簿(全建統一様式第5号)`PRN_1250` → Excel
建設現場へ提出する標準様式。1隊員 = 数行のブロック。

主な記載項目:
- 事業所の名称(現場名)/ 所長名 / 一次・二次会社名
- 番号 / フリガナ・氏名 / 職種(警備)/ ※
- 雇入年月日 / 生年月日 / 現住所 / 連絡先(TEL)
- 経験年数 / 年齢 / 家族連絡先(氏名・続柄・TEL)
- 最近の健康診断年月日 / 血圧 / 血液型
- 特殊健康診断年月日 / 種類
- 健康保険(協会けんぽ/組合)/ 年金保険(厚生年金・基金/受給者)/ 雇用保険(一般保険・番号)
- 教育・資格・免許(雇入時・職長特別教育 / 技能講習 / 免許)

出力オプション:入社前経験年数を含む / 社会保険情報を印刷 / 建退共手帳の有無 / 建設産業用として印刷 / 緊急連絡先の氏名を印刷しない

### 2-2. 警備契約書(1号 / 2号)`RPT_109020`
「契約の概要について記載した書面(締結後)」=**警備業法第19条第2項・施行規則第34条第2号**準拠。
2号警備の場合の20項目テンプレート:

1. 警備業務を行う期間
2. 警備業務を行う日及び時間帯
3. 警備業務を行う場所
4. 警備人員及び担当業務
5. 警備員が有する知識及び技能(例:交通誘導警備2級検定合格者 等)
6. 警備員が用いる服装
7. 使用する機器又は各種資材(無線機・手旗・誘導灯・警笛 等)
8. 負傷等の事故発生時の措置
9. 報告の方法・頻度・時期(警備報告書)
10. 警備料金・その他費用(基本単価・残業単価・**キャンセル料規定**:前日17時前=無料/50%、以降=全額 等)
11. 支払の時期及び方法(締日・振込)
12. 警備業務の再委託に関する事項
13. 免責に関する事項
14. 損害賠償の範囲・賠償額(警備業賠償責任保険:対人/対物限度額)
15. 契約の更新
16. 契約の変更
17. 契約の解除
18. 苦情受付窓口
19. 特約事項
20. 契約締結年月日
+ 末尾:確認者・捺印欄

→ 配置先マスタ・得意先・契約データから差し込み生成。1号(施設警備)用テンプレートも別途。

## 3. 社内・経営帳票

| 帳票 | 区分 | 元データ |
|------|------|---------|
| 管制日報 | 日次 | 勤務実績(`DPI_4010` 印刷=管制日報) |
| 勤務実績表 | 日次/月次 | 勤務実績 |
| **法定三帳簿:労働者名簿** | 随時 | 隊員 |
| **法定三帳簿:出勤簿** | 月次 | 勤務実績 |
| **法定三帳簿:賃金台帳** | 月次/年次 | 給与 |
| 給与明細書 / 勤務明細付き給与明細書 | 月次 | 給与 |
| 振込データ(全銀フォーマット等) | 月次 | 給与・振込情報 |
| 入金一覧 / 売掛金残高 / 得意先元帳 | 月次 | 入金 |
| 売上収支表 | 経営 | 請求・給与・原価 |

## 実装上の留意

- **インボイス制度対応**:登録番号、税率別(10%/8%軽減)の区分記載、適格請求書の要件を満たす。
- **端数処理**:配置先ごとに切捨/四捨五入/切上、外税/内税を設定可能(`05_business-rules.md`)。
- **複数振込先口座**:請求書に複数行表示。
- **帳票の出し分け**:勤務グループ・配置先選択・明細合算・住所有無などの印刷オプションを多数持つため、帳票テンプレートはパラメータ駆動で設計する。
- 出力形式:PDF(対外)+ Excel/CSV(名簿・振込・分析)。
