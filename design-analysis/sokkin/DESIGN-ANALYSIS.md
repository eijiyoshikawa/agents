## 4. デザインスタイル・エステティック

### 全体的な印象
- **モダン・コーポレート・スタートアップ**: 洗練されたプロフェッショナル感
- **ダーク基調**: 黒/ダークネイビーをベースとした力強いデザイン
- **ミニマル**: 余白を活かしたクリーンなレイアウト
- **動的要素**: ファーストビューに動画またはアニメーション使用の可能性大

### デザインの方向性
- デジタルマーケティング企業として「先進的」「信頼感」を重視
- 「野望に仕える」というアグレッシブなコピーに合わせた力強いビジュアル
- 元サイバーエージェント出身者の企業として、モダンなテック企業感

## 5. カラーパレット（推定）

### プライマリカラー
```
■ ブラック / ダークネイビー  #0A0A0A ~ #1A1A2E  （メイン背景）
■ ホワイト                  #FFFFFF              （テキスト・コントラスト）
■ アクセントブルー           #0066FF ~ #3B82F6    （CTA・リンク・ハイライト）
```

### セカンダリカラー
```
■ ライトグレー              #F5F5F5 ~ #F8F9FA   （セクション背景交互）
■ ダークグレー              #333333 ~ #4A4A4A   （ボディテキスト）
■ グラデーション             ブルー → パープル系    （アクセント装飾）
```

### 使用イメージ
- ヒーロー: ダーク背景 + ホワイトテキスト
- サービスセクション: ホワイト or ライトグレー背景
- CTAボタン: アクセントブルー
- フッター: ダーク背景

> **要確認**: 実サイトでブラウザのDevToolsを使用し、正確なカラーコードを取得してください。

## 6. タイポグラフィ（推定）

### フォントファミリー
```css
/* 日本語 */
font-family: "Noto Sans JP", "Hiragino Sans", "Hiragino Kaku Gothic ProN", "メイリオ", sans-serif;

/* 英語・ブランドテキスト */
font-family: "Inter", "Montserrat", "Poppins", sans-serif; /* いずれかの可能性 */
```

### 見出しスタイル
| 要素 | サイズ（推定） | ウェイト | 用途 |
|------|-------------|---------|------|
| H1 | 48-64px | Bold (700-900) | ヒーローコピー「野望に仕える」 |
| H2 | 32-40px | Bold (700) | セクション見出し |
| H3 | 24-28px | Semi-Bold (600) | サブ見出し |
| Body | 15-16px | Regular (400) | 本文 |
| Caption | 12-14px | Regular (400) | 補足テキスト |

### テキストスタイリング
- 英語テキスト: 大文字（例: "ALWAYS SOKKIN", "SOKKIN AGENT"）
- 日本語コピー: ゴシック系、やや太めのウェイト
- レタースペーシング: 英語テキストは広め（0.05-0.1em）

## 8. レイアウトパターン

### グリッドシステム
- **最大幅**: 1200px ~ 1400px（推定）
- **カラム**: 12カラムグリッド
- **サービスカード**: 2×2 or 4列グリッド
- **余白**: セクション間 80-120px

### レスポンシブ
- **デスクトップ**: 1200px+ — フル表示
- **タブレット**: 768-1199px — 2カラム→1カラム
- **モバイル**: ~767px — シングルカラム + ハンバーガーメニュー

## 9. アニメーション・モーション（推定）

### ファーストビュー
- 背景動画 or パーティクルアニメーション（ダーク背景上）
- テキストのフェードイン / スライドアップ

### スクロールアニメーション
- セクションごとのフェードイン（Intersection Observer）
- 数値カウンターのアニメーション（0→目標値）

### ホバーエフェクト
- ボタン: 背景色の変化 + scaleまたはtranslate
- カード: subtle shadow / lift効果
- ナビリンク: underline animation

### ページ遷移
- スムーズスクロール（アンカーリンク）
- ページローダー（ロゴアニメーション）の可能性
