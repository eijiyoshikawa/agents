# 役員会議 議事録（board_meetings）

株式会社LET の役員会議の議事録・まとめを蓄積するフォルダ。

## 運用ルール
- 会議ごとに Notion のアジェンダ／議事録ページ URL を共有 → `YYYY-MM-DD.md` にまとめて保存する。
- 各ファイルは以下の構成を基本とする：
  1. メタ情報（会社／期・開催日・種別・出典URL・目的）
  2. エグゼクティブサマリー（3行）
  3. アジェンダ項目ごとの要点・進捗・課題
  4. 経営判断が必要な論点
  5. ToDo / アクションリスト（担当・期限つき）
  6. 決定事項・重要論点／保留
- 決定事項欄が会議中未記入の場合は「未記入」と明記し、確定後に追記する。
