## 7. 社内AIシステム（マスターAI）と情報セキュリティ ★重要

### マスターAIの構想（8割完成／認証が残課題）
- Google カレンダー・Gmail・Drive と連携し、**翌日の商談に応じた資料を朝6時頃に自動生成**してカレンダーに配置
- カレンダー見出しに「SNS／AI／コミット／人証」等のワードを入れると、対応資料が自動で用意される
- SNS分析レポート・求人票作成なども自動化済み（1件あたりAPIコストは数十円程度）
- 手作業で10個作るより、システムで10個作れば数百円で済む → コスパで社内システムに寄せる

### 社内集約の方針（意思決定）
- 個人PCで各自がClaude課金する現状には、**①設定ミスでの情報漏洩 ②提案パターンの学習・流出 ③退職時に社内ナレッジが個人クラウドへコピーされるリスク**
- 真っさらな個人AIよりも、資料を読み込んだ社内AIの方がアウトプットの質が高い → **「社内PC/社内AIを使わざるを得ない」状況を作り、自然に集約を促す**
- 参考：サイバーエージェントが広告ディレクターを削減できたのは、ナレッジを社内蓄積し誰でも高品質な成果を出せる仕組みを作ったから

### Claude チームプランへの移行
- 現在使用は Claude・Vercel・GitHub の3ツール程度
- チームプラン：5名以上前提、標準シート $25/人・プレミアム $125/人（**計10万円未満見込み**）
- 管理者権限でユーザー削除・制限が可能 → 退職時のリスク管理がしやすい
- Anthropic API は従量課金で運用、上限到達時に通知が来る仕組みは整備済み
- 参考：Amazon は Kilo（Cursorベース）を従量課金＋iPad発行＋コンサル以上のみ使用で運用

### セキュリティ実装
- **GitHub はプライバシーモード**（外部からは存在のみ、中身は非公開）。**社内Claudeからのみアクセス可能**にする構築を進める
- 個人PCからのアクセス制限・利用ログ管理は引き続き検討
