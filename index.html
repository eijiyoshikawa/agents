戦略オプション

戦略A: Instagram起点コミュニティ型スモールスタート 推奨 実現可能性: HIGH

月2回・平日昼間の格安レンタルスタジオで開始。Instagramで「30代以上×ダンス経験者」コミュニティを形成。初回体験無料で心理的ハードルを下げ、5人の固定メンバー確保後に週1回へ拡大。

メリット

  • 月2回なら固定費6,000〜8,000円と極めて低リスク
  • 平日昼間は子育てひと段落層にドンピシャ＆スタジオ代最安
  • 1,000円/回で「試しに行ってみよう」のハードルが極低

  • 需要確認してから段階拡大、赤字リスク最小

  • 月2回では収益がほぼゼロ（検証期間と割り切る）
  • Instagram運用の継続的な負荷

  • 拡大スピードが遅い（半年〜1年の助走期間）

Devil's Advocate（批判的検証）

1. ニッチすぎる市場リスク

前提への疑問：「30代以上×経験者限定」に十分な市場規模があるか？

リスク：推計3,000〜5,000人の5〜10%（150〜500人）しか実行動層でない可能性。

対策：初月は無料体験会3回で実需を検証。5人集まらなければ「25歳以上」にピボット。

2. 低価格の逆効果

リスク：1,000円が「質が低い」シグナルに。経験者ほど「安かろう悪かろう」を警戒。

対策：安さの理由を明示。将来1,500円への値上げ余地を設計に組み込む。当日無断キャンセル3回で参加お断りルール。

3. SNSリーチの限界

リスク：Instagram上のダンスコンテンツは若年層優位。30代以上はGoogle検索・口コミが主流。

対策：ジモティー・ストアカ・Googleマップ等マルチチャネル必須。地域特化ハッシュタグ戦略徹底。

4. 1人運営の持続性

リスク：レッスン・SNS運用・予約管理・会計を1人で回す燃え尽きリスク。

対策：月2回スタートで負荷検証。予約はGoogleフォーム、会計はfreee無料プランで自動化。

5. コミュニティの内輪化

リスク：少人数が仲良くなりすぎて新規参入しにくい雰囲気に。

対策：月1回のオープンクラスと友達紹介特典で新規流入を仕組み化。

6. レンタルスタジオの安定確保

リスク：格安スタジオは人気が高く、毎週同じ条件確保が困難。場所が変わると離脱の原因に。

対策：候補3箇所以上リストアップ。定期利用契約があるスタジオを優先。LINEで毎回情報共有。

再定義された課題

  1. 本質は「ダンスクラスの開講」ではなく「30代以上のダンス経験者コミュニティの創出」
  2. 1,000円/回は「安さで勝負」ではなく「最初の5人を集めるための参入障壁の除去」
  3. 「経験者限定」は差別化の武器であり市場を狭めるリスク。3ヶ月後にピボット判断基準を持つ
  4. 最大のリスクは「集客失敗」ではなく「検証なき撤退」。データを取りながら低コストで回す
  5. インストラクターのSNS発信より、参加者が自発的に「今日のレッスン楽しかった」と投稿したくなる体験設計の方が10倍重要

推奨事項まとめ

最優先（今すぐやること）

  1. クラス名を「REBOOT DANCE」に決定し、Instagram・LINE・チラシで統一表記
  2. 最初の3名は既存人脈から確保する（SNSだけに頼らない）
  3. 格安スタジオ（1,500円/時間以下）を調査。公共施設・区民センターを優先
  4. Instagram+LINE公式の2アカウントを開設する
  5. ダンス動画3-5本を撮り溜めして投稿のストックを確保

開講後に意識すること

  • 「経験者限定」のポジショニングを曖昧にしない（差別化の根幹）
  • 1,000円/回は参入価格。6ヶ月後に1,500円への改定を計画
  • レッスンの「質」より参加者が「また来たい」と思える体験設計が重要
  • インストラクター本人の顔出しコンテンツが最も効果的
  • 完璧を目指さない。スマホ1台で撮影・編集・投稿を完結させる
  • レクリエーション保険（30円/人/回）への加入を推奨

ピボット判断基準

  • 3回連続で平均3人未満 → ターゲットを「25歳以上」に拡大検討
  • Instagram 1ヶ月でフォロワー50未満 → ジモティー・ストアカに注力
  • メンバー3人以下が1ヶ月続く → 1ヶ月休止・再募集判断
  • 6ヶ月後に安定8名以上 → 週1回化＋価格改定＋2クラス目検討
