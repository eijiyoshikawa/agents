# PartnerSales スタッフ運用マニュアル

紹介報酬管理システム「PartnerSales」を社内スタッフが日常運用するための手引きです。
（システムの構築・環境設定は `docs/RUNBOOK.md` を参照）

---

## 0. ログイン

- 管理画面URL: `https://（本番URL）/staff/login`
- **合言葉**を入力してログイン（合言葉は管理者から共有されます）
- ログイン状態は12時間で切れます。切れたら再ログインしてください
- 終わったら右上「ログアウト」

> パートナー（紹介会社）は別のログイン画面 `/login` を使います。スタッフ用とは別です。

---

## 1. 画面の構成

| メニュー | 用途 |
|---------|------|
| **ダッシュボード** | 全体の紹介ツリー・売上ランキング・重点サポート候補・支払い対象件数 |
| **サービス・報酬** | 各サービスの紹介報酬（tier1〜3）の確認 |
| **スタッフ管理** | 成約入力 / 支払い精算 / パートナー登録（日常業務はここ） |

---

## 2. 紹介報酬のしくみ（基本）

- 報酬は **クライアントとの契約額**を基準に計算します
- クライアントを紹介したパートナーから **上に最大3段**へ分配します

| 段 | 受け取る人 | 例（SNS運用 100万契約） |
|----|-----------|------------------------|
| tier1 | クライアントを直接紹介したパートナー | 10% = 100,000円 |
| tier2 | その紹介者（1段上） | 3% = 30,000円 |
| tier3 | さらに1段上 | 2% = 20,000円 |

- 弊社が直接契約したパートナー（紹介元なし）が紹介した場合は **tier1のみ**
- パートナー自身が顧客になる「自己成約」は **tier1を出さず**、上位のtier2/tier3には支払います
- 報酬率はサービスごとに異なります（「サービス・報酬」画面で確認）

---

## 3. パートナーを登録する（アポ後）

商談・アポイントが済んだ紹介会社をシステムに登録します。

1. 「**スタッフ管理**」→「**パートナー登録**」タブ
2. 入力：
   - **会社名**（必須）
   - **担当者名**
   - **メールアドレス**（ここに**ログイン情報が自動送信**されます。正確に入力）
   - **紹介元**（プルダウン）：この会社を紹介してくれた既存パートナーを選ぶ。
     直接開拓なら「（なし / ルート登録）」
   - **ログインID**：空欄でOK（自動発行されます）
3. 「**登録してログイン情報を発行**」を押す
4. 完了画面に **招待コード / 個別ページ / ログインID** が表示されます

### ログイン情報の渡し方
- **メール送信が有効な場合**：入力したメールアドレスへログインID・パスワードが自動送信されます
- **メール未設定の場合**：完了画面に**パスワードが表示**されるので、担当者へ手動で連絡してください
  （※パスワードは後から確認できません。表示時に必ず控える）

> パートナーには「ログインURL（`/login`）＋ ログインID ＋ パスワード」を伝えます。
> 紹介を広げてもらうには、そのパートナーの**招待コード**も伝えてください（新しい紹介先の登録時に「紹介元」として使われます）。

---

## 4. 成約（契約）を入力する

クライアントと契約が決まったら入力します。これが報酬計算の起点です。

1. 「**スタッフ管理**」→「**成約**」タブ
2. 入力：
   - **サービス**：契約したサービス
   - **紹介パートナー（tier1）**：このクライアントを紹介したパートナー
   - **クライアント名**：契約した顧客名
   - **契約金額**（円）
   - **ステータス**：
     - `pending`（見込み）… まだ確定でない。報酬は「見込み」に計上
     - `confirmed`（確定）… 受注確定。**報酬が確定**として計上される
     - `paid`（入金済み）… 入金まで完了
   - **自己成約**：パートナー自身が顧客の場合だけチェック
3. 「**成約を登録**」

### ステータスの変更
一覧の各成約の右側プルダウンで、後から `pending → confirmed → paid` に変更できます。
**`confirmed` 以上にした時点で報酬が「確定」**になり、パートナーのマイページや支払い対象に反映されます。

---

## 5. 報酬の支払い（精算）

支払いは **弊社からの銀行振込のみ**。紹介者から**都度請求書**を受け取って処理します。

### 支払いのルール
- パートナーごとの**未精算の確定報酬が ¥50,000 に達するまでは支払いません**（それまでは繰越）
- ¥50,000 に達すると「**請求書発行依頼**」の状態になります

### 操作手順（「スタッフ管理」→「支払い」タブ）
1. 一覧で各パートナーの「確定累計 / 振込済 / 請求中 / 未精算」と状態を確認
2. **状態が「請求書発行依頼」** のパートナー → 紹介者に請求書発行を依頼
3. 請求書を受け取ったら「**請求書受領**」ボタン → 請求書番号を入力（任意）→ 状態が「入金待ち」に
4. 銀行振込を実行したら、下の「精算レコード」で該当行の「**振込完了**」ボタン → 状態が「振込済」に

> 振込済みになった分は「振込済み累計」に加算され、未精算から差し引かれます。

## 6. パートナーの状況を見る

- **ダッシュボード**：全パートナーの紹介ツリーが一覧できます。各社の総売上・確定報酬も表示
  - **リーダーボード**：成績順。誰がよく売れているか
  - **重点サポート候補**：休眠気味・伸び悩み等、フォローすべきパートナーの提案
- パートナー名をクリック → その会社の詳細（ツリー・報酬明細・月次締め・支払い状況）

## 7. よくある質問

**Q. パートナーがパスワードを忘れた**
A. 現状はパスワード再設定機能が無いため、「パートナー登録」で同じ会社を…ではなく、管理者に連絡してください（DBで再発行）。※今後の改善予定項目です。

**Q. 紹介元を間違えて登録した**
A. ツリー（親子関係）の修正はDB操作が必要です。管理者に連絡してください。

**Q. 報酬額が違う気がする**
A. 「サービス・報酬」で率を確認。報酬は `confirmed`/`paid` の成約のみ確定計上され、`pending` は見込みです。成約のステータスと金額を確認してください。

**Q. ログインできない（スタッフ）**
A. 合言葉が正しいか確認。12時間でセッションが切れます。それでもダメなら管理者へ。

## 8. 用語

| 用語 | 意味 |
|------|------|
| パートナー | 紹介会社 |
| 招待コード | パートナーが新しい紹介先を連れてくるときの識別コード |
| 成約 / Deal | クライアントとの契約。報酬計算の起点 |
| tier1/2/3 | 紹介の段（1=直接紹介、2=その上、3=さらに上） |
| 未精算 | 確定済みだがまだ支払っていない報酬 |
| 繰越 | 支払い下限（¥50,000）に満たず次回に持ち越す状態 |
