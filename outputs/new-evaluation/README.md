## 制度の骨格（1分サマリー）

- **個人評価（昇降格）＝役割配分方式（2026-09-07 全面変更・正本: [PERSONAL-EVAL.md](./PERSONAL-EVAL.md)）**: 本人評価粗利＝当期粗利×役割配分率（SNS初回 営業50/マーケ50・更新後10/90・クロスセル50/50・コミット型20/50/30・紹介RA50/CA50・BPO100%）×本人担当割合。昇格＝max(G×110%, N)＋定性＋役割実証3ヶ月＋総合80点。補助指標は不採用。降格は別手続き（暫定: G×70%未満×1期）。旧・月給×1.15×倍率分母と両建て100%は昇降格用途では廃止
- **ボーナス＝営業マーケ合同プール方式（2026-09-07 全面変更・確定)**: 原資＝半期の実チーム粗利（売上−広告費−外注費・両建て除去）× **15%**。ガードなし完全連動（営業利益不問）。分配＝ランクウェイト R1 0.8/R2 1.0/R3 1.2/R4 1.4/R5 1.6 の比例（全員同ランクなら均等割・期中入退社は月数按分）。確定額は半期末に会社通知。~~チーム達成率段階制・青天井~~は廃止
  - **例外**: ④不動産/BPO職は**原価率判定** — 半期の原価率（原価÷売上）40%以下で1ヶ月支給（プール対象外）。CA職もプール対象外（賞与は別途設計）
- 運用開始の前提: 各人のG/N目標設定・案件台帳（案件ID・フェーズ・担当割合）整備・MVV対応付け（PERSONAL-EVAL.md §7）
- ランク R1〜R5・月給テーブル（R2スタート・+2/+3/+4/+5万）は変更なし。昇降格の判定手続きは PERSONAL-EVAL.md（半期査定・飛び級なし・等級内査定昇給なし）
- 計上は月次発生ベース（MF実仕訳一致）・個人評価は役割配分率で按分（両建て100%は廃止）・クローバックは発生期マイナス計上
- 会社赤字を理由とする支給ゲート・減額条項は**設けない**（プールは粗利連動・営業利益不問のため原則維持）
