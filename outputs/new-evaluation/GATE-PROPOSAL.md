# 提案: 会社業績ゲートの設計（新評価制度）

作成: 2026-08-25 ／ ステータス: 提案（要決定）
背景: 試算01で「営業のボーナスライン（常時5件）＜ 会社の損益分岐（常時6件）」の逆転構造が判明。会社が赤字のまま個人ボーナスの支給義務だけが発生しうる。

---

## 0. 解決したい問題（再確認）

- 粗利3倍基準は「個人の物差し」としては機能するが、**役割売上の両建て**により職種別の達成が会社の黒字を保証しない
- 特に営業: 役割売上が全案件を取り込むため達成が相対的に早く、会社赤字とボーナス達成が同時に起きる（試算01: 会社年間▲81万の中で営業H2ボーナス34.5万が発生）
- 一方で「個人が達成したのに会社都合でゼロ」は最悪のモチベーション毀損。**財務安全性と納得感の両立**が設計目標

## 1. 設計オプション（4案）

### 案A: 支給ゲート型（on/off 条件）
最終達成率100%以上でも、**会社の半期業績が条件を満たさなければ支給しない/保留**。

- A1: 全社営業利益（半期）≥ 0 で支給
- A2: 評価対象事業群の貢献利益（粗利−対象職種人件費）≥ 0 で支給
- A3: **繰延方式** — 条件未達の半期は支給を保留し、翌半期に会社条件が回復したら遡って支給（翌半期も未達なら失効 or 50%減額）

試算01への適用（ゲート=全社でなくこの事業単体・間接費前とした場合）: H2は事業黒字（+139.5万/半期）のため営業ボーナスは支給される。間接費込みでゲートを組むとH2も赤字となり不支給。
**評価: 財務安全性は直撃で確保。ただし「達成→ゼロ」の崖があるため、採るならA3（繰延）一択。**

### 案B: 会社係数型（3層目の連続係数）
```
最終達成率 = 個人達成率 × チーム係数 × 会社係数
会社係数 = clamp( 0.8 + 0.3 × 会社達成率, 下限0.8 〜 上限1.1 )
会社達成率 = 全社粗利 ÷ 全社人件費×3   ※全社を個人と同じ3倍ロジックで測る
```
**評価: 崖がなく全社連帯が生まれるが、係数が2段掛けになり「分かりにくかった旧制度」への逆戻りリスク。** 下限0.8なら財務安全性の担保も部分的（達成者の支給は止まらない）。

### 案C: 原資連動型（ボーナスプール）
半期営業利益の一定割合（例30%）をボーナス原資とし、達成者に配分（1人1ヶ月分を上限）。利益ゼロなら原資ゼロ。
**評価: 支給総額が必ず利益の範囲内に収まり財務安全性は完全。ただし「粗利3倍→1ヶ月」という約束のシンプルさを壊し、金額が事前に読めない。今回の制度思想と合わない。**

### 案D: 基準内包型（営業の倍率を3.5倍に引き上げ、ゲー​ト自体を不要にする）
営業職のみ倍率を 3.0 → **3.5** にする。

```
営業の必要粗利/月 = 30万 × 1.15 × 3.5 = 120.75万
　　　　　　　　 = チーム全体の人件費 (105万 × 1.15) = 会社の損益分岐（間接費前）
```

**現体制では営業のボーナスライン＝会社の損益分岐が数式上ぴったり一致する**（常時6件）。「営業が達成しているなら少なくともこの事業は黒字」が構造的に保証される。

- 根拠の説明もしやすい: 営業の役割売上は**全案件を取り込む**（両建てで最も広い物差し）ため、分母も広く取るのが公平
- 注意: この一致は「マーケ3名＋営業1名」の体制比に依存する。体制が変われば倍率の再計算が必要（例: マーケ4名なら3.9倍相当）。倍率を固定するなら「3.5倍」を採用し、体制変更時に見直す運用
- 変形案D': 倍率3倍のまま、営業粗利から運用人件費の按分を控除する方法もあるが、**按分は恣意性排除の方針に反するため非推奨**

## 2. 比較表

| | 財務安全性 | シンプルさ | 納得感（崖のなさ） | 労務リスク |
|---|---|---|---|---|
| A1/A2 ゲート | ◎ | ○ | ×（達成→ゼロ） | 中（不利益変更の説明要） |
| A3 繰延ゲート | ◎ | ○ | △（もらえるが遅れる） | 小〜中 |
| B 会社係数 | △（下限次第） | ×（3層掛け） | ◎ | 小 |
| C プール | ◎ | × | △ | 中 |
| D 営業3.5倍 | ○（間接費前まで） | ◎ | ◎（自分の物差しのまま） | 小（制度開始時に織込み） |

## 3. 推奨: 「D＋A3」の二段構え

1. **一段目（構造の修正）= 案D**: 営業職の倍率を3.5倍にし、「営業達成＝事業黒字」を数式レベルで保証する。日常の制度は今まで通り「自分の達成率だけ見ればいい」シンプルさを維持
2. **二段目（最終安全弁）= 案A3**: それでも**全社営業利益（半期・間接費込みの実PL）がマイナス**の場合は、ボーナス支給を翌半期に繰延。翌半期の全社営業利益がプラスなら全額遡及支給、マイナスなら50%に減額して支給（失効はさせない — 納得感優先）
   - 通常時は発動しない「保険」であり、従業員向け説明も「会社が半期赤字のときだけ支払いタイミングが後ろにずれる」で済む
   - 新制度の開始時から就業規則・賃金規程に「賞与は会社業績により支給時期の繰延・減額があり得る」旨を明記（後出しにしない）

### 試算01への適用結果（D＋A3を入れた場合）

| | 現行案(3倍・ゲートなし) | D＋A3 適用後 |
|---|---|---|
| 営業H1 (81.2%→3.5倍換算69.6%) | 未達 | 未達（変わらず） |
| 営業H2 | 139.1%達成 → 34.5万支給 | 3.5倍換算 **119.2%達成**。事業単体はH2黒字だが、全社営業利益（間接費込み）が赤字なら**翌半期へ繰延** |
| 会社の年間損益 | ▲115.5万 | ▲81万（繰延中）〜▲115.5万（翌期回復時に支給） |

- Dだけでも「6件未満で営業にボーナス」は消える。A3は間接費・他事業込みの最終防衛線

## 4. 運用ルール詳細（推奨案ベース）

- **ゲート指標**: 全社営業利益（MF実仕訳・半期累計）。既存の財務ダッシュボードの月次PL集計をそのまま使える
- **判定タイミング**: 半期査定の確定時（10月初 / 4月初）
- **個人ページでの見せ方**: 「会社ゲート: OPEN / HOLD」のステータスのみ常時表示（全社営業利益の金額そのものは経営陣ページ限定 — 従業員向けマスク方針と整合）。HOLD時は「達成分のボーナスは会社業績回復後に支給されます」と表示
- **繰延の記録**: 繰延額・発生半期・支給予定を個人ページに明示（消えない安心感）

## 4.5 体制変更シミュレーション: 営業2名＋マーケ3名（2026-08-25 追記）

前提: 倍率は**固定3.5倍のまま**。人件費 = (30×2+25×3)×1.15 = **155.25万/月** → 会社損益分岐は常時6.47件 → **7件**。

| ケース | 達成者の最終達成率（チーム係数込み） | 会社損益/月 |
|---|---|---:|
| 片方5件・片方0件 | 99.4% × 0.849 = **84.4%（未達）** | ▲35.25万 |
| 片方6件・片方0件 | 119.3% × 0.879 = **104.8%（ギリ達成）** | ▲11.25万 |
| 片方7件・片方0件 | 139.1% × 0.909 = **126.4%（達成）** | +12.75万 |
| 両者6件ずつ（計12件） | 119.3% × 1.058 = **126.1%（達成）** | **+132.75万** |

読み取れること:

1. **1名時代の「営業達成⇔会社黒字」の完全一致は崩れるが、ズレは小さい。** 最悪ケース（片方6件・片方0件）でも会社の赤字幅は月▲11万程度。しかもこの赤字は「2人目の営業が売れていない」という採用・マネジメント側の問題であり、達成者にボーナスを出すこと自体は健全
2. **チーム係数（職種単位）が自動の緩衝装置として働く。** 相方がゼロだとチーム達成率が下がり、達成者の必要件数が実質5.03件→5.77件に上がる。仲間が売れないと自分のハードルも上がる=営業同士の連帯が式に織り込まれる
3. **残った小さなズレはA3の全社ゲート（半期赤字なら繰延）が拾う。** D＋チーム係数＋A3の三層で、体制が変わっても財務安全性は維持される
4. マーケ3名のライン（常時11件）は不変。営業2名が両方達成する水準（計12件）ではマーケも達成圏に入り、会社は月+130万超の黒字

**結論: 倍率は固定3.5倍でよい。** 体制連動式（総人件費÷営業人数で毎回再計算）にすると営業2名時に1人あたり2.25倍まで下がり、「粗利3倍」の全社メッセージと矛盾する上に査定ごとに基準が動いて不信を生む。固定3.5倍なら基準は一生変わらず、体制変化の吸収はチーム係数とA3ゲートに任せるのが筋が良い。マーケ比率が大きく変わる場合（例: マーケ5名/営業1名）のみ制度改定として見直す。
