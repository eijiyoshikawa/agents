## 候補4案

| 案 | 式 | 係数の範囲 | 性格 |
|---|---|---|---|
| 1. 段階式（旧v1.4型） | 表引き: 120%+→1.10 / 100〜119→1.00 / 80〜99→0.90 / 70〜79→0.80 / 60〜69→0.70 / 60%未満→0.60 | 0.60〜1.10 | 表で一目瞭然。ただし境界に崖 |
| 2. 連続マイルド | 係数 = 0.7 + 0.3 × チーム達成率（達成率は120%でクランプ） | 0.70〜1.06 | 崖なし・エース保護・連帯圧は中 |
| 3. 連続シャープ | 係数 = 0.5 + 0.5 × チーム達成率（同上） | 0.50〜1.10 | 崖なし・連帯圧強・チーム不調時の下げ幅大 |
| 4. 平方根 | 係数 = √チーム達成率（同上） | 0.00〜1.095 | パラメータ不要で滑らか。ただしチーム0%で係数0・現場への説明がしにくい |

共通の性質（どの案でも成り立つ）:
- **チーム100%なら係数1.00** — 「チームが目標どおりなら自分の成績がそのまま評価」
- 乗算構造のため、**チームが好調でもサボった個人は救われない**（S6: 個人60%はどの案でも60%前後のまま）

## 推奨: 案2 連続マイルド（0.7 + 0.3 × チーム達成率）

1. **崖がない** — 段階式はチーム79.9%と80.0%で最終評価が10pt飛ぶ。査定・給与に直結する数字に崖は不信の元
2. **チーム100% ⇒ 係数1.00** が覚えやすく、説明が一行で済む
3. **エースを潰さない** — S5（相方が売れない営業エース）で係数0.6をかける段階式はエースの離職リスクをそのまま制度化してしまう。採用失敗の帰責はマネジメント側であり、個人の成績を7割未満まで削るべきではない
4. **連帯圧は十分残る** — チーム未達なら最大▲30%のペナルティ。個人100%ちょうどではチーム未達だと達成できない（チーム100%以上が必要）ため、「自分だけ良ければいい」は成立しない
5. 営業2名体制の検証（GATE-PROPOSAL §4.5）でも、このマイルド式が「相方不調で実質必要件数が上がる」自然な緩衝装置として機能することを確認済み

### 変形オプション（必要なら）
- **職種別の傾き**: マーケ（真のチーム制作）のみシャープ式、営業（個人商店色が強い）はマイルド — 連帯圧を職種の実態に合わせられるが、式が2本になり説明コスト増。**推奨は全職種統一のマイルド1本**

## 連続マイルドの詳細解説（2026-08-25 追記）

### 式の本質 = 「評価の30%をチームに預ける」
一般形 `係数 = (1−w) + w×チーム達成率` の w=0.3 版（シャープ式は w=0.5 版）。
最終評価の70%は自分の成績で確定し、30%だけがチームに連動する。**実質の決定変数はチームウエイト w**。

### 係数の早見表
| チーム達成率 | 係数 | 最終100%に必要な個人達成率 |
|---:|---:|---:|
| 0% | 0.70（下限） | 142.9% |
| 60% | 0.88 | 113.6% |
| 80% | 0.94 | 106.4% |
| **100%** | **1.00** | **100%** |
| 110% | 1.03 | 97.1% |
| 120%以上 | 1.06（上限） | 94.3% |

- チーム10pt変動 → 係数3pt変動（崖なし）。チーム100%が中立点
- 「チームが沈むほど自分の必要達成率が上がる」= 罰ではなく必要ラインが静かに上がる連帯圧

### 効き方の非対称性（重要）
- エース級（個人120%）はチーム60%でも 105.6% で生き残る
- **当落線上（個人100〜110%）はチーム不調で未達に落ちる**（例: 個人105%×チーム75% → 97.1%）
- → 一番動機づけたい当落線上の層に一番強く連帯圧がかかる合理的な構造

### 「助けると得」の実例（マーケ3名）
- A=120%, B=90%, C=75%（チーム95%・係数0.985）→ A最終118.2%
- Aが自分の数字を10pt落として仲間を引き上げ A=110%, B=C=100%（チーム103%・係数1.031）→ A最終113.4%
- 教える・巻き取るがほぼ損にならず、チームが伸びれば自分も上振れる

### 上限・下限の根拠
- **上限1.06**: 無制限だとチーム爆発時に個人80%までフリーライド達成する。1.06なら救済は個人94.3%以上（ほぼ達成者）に限定
- **下限0.70**: チーム壊滅でも個人成果の7割は残す最低保証。下限なし（平方根式）はチーム崩壊時に成果消滅→退職連鎖リスク

### 従業員向け説明（3行）
1. チームが目標どおり(100%)なら、あなたの成績がそのまま評価
2. チームが超えたら最大+6%、届かなければ最大▲30%の補正
3. 個人ページに「個人・チーム・最終」の3本のゲージが常時表示（財務連動）
