## 1. 超過達成ボーナス 段階制【2026-08-25 決定 / 2026-08-28 判定指標を変更】

判定は**チーム達成率**で行う【2026-08-28 変更。旧: 最終達成率（チーム係数適用後）】。
チームが段階に到達すれば、そのチームのメンバー全員に各自の月給ベースで支給する（個人下限ガードなし・純チーム連動）。

| チーム達成率 | ボーナス |
|---|---|
| 100%以上 120%未満 | 月給 **1ヶ月** |
| 120%以上 150%未満 | 月給 **1.5ヶ月** |
| **150%以上** | 月給 **2ヶ月** |
| 100%未満 | なし |

- 支給は半期査定ごと（年2回）。年間最大 = 月給4ヶ月分
- 財務健全性: チーム150%はチーム全体で半期基準の1.5倍の粗利を生んでいる状態であり、全員への追加支給はそのチーム粗利で賄われる。**段階が上がるほど会社の取り分も増える**ため財務中立以上（旧設計からこの性質は不変。むしろ「チームが原資を稼いだときだけ全員に払う」ため個人判定より保守的）
- 1名チーム（現状の営業・CA・BPO）はチーム達成率＝個人達成率のため、事実上個人成績で段階が決まる
- 複数名チーム（マーケ3名）では150%到達に全員平均150%が必要なため、上位段階は実質的に団体戦になる（設計意図どおり）

## 2. 月給テーブルの設計原則

1. **基準連動**: 月給が上がると粗利基準（×3 / 営業×3.5）も自動で上がる。昇給1万円 → 必要粗利は月+3.45万（営業は+4.03万）。**昇格者が基準を守る限り、昇給原資は本人の粗利増で賄われる**（昇給インフレが財務を毀損しない自己均衡構造）
2. 昇給幅は覚えやすい階段で、上位ほど幅を広げR5を「目指す価値のある頂点」にする（確定: +2万→+3万→+4万→+5万。当初の等差案 +2/+3/+3/+4 は不採用）
3. スタート位置は2案（→ #8 の決定と連動）

参考: 全員ちょうど100%（1ヶ月×2回）の場合 → 人件費3,606万 vs 実粗利下限7,535万 → 残り+3,928万

**結論: この制度に「中間値」という概念はなく、上限吐き出しは常に財務最良のケース。**
ボーナスは粗利基準の達成に完全連動する後払いのため、支払額が最大になる状況＝粗利が最大の状況。
支払いだけ増えて粗利が付いてこないケースは構造上存在しない（基準連動＋段階制の帰結）。
会社が財務リスクを負っているのは固定部分（給与）だけであり、それは試算01（受注ペース下限）の話に帰着する。

## 4. 昇格・降格の閾値（#10 の提案）

判定指標は**個人達成率**【2026-08-28 変更。旧: 最終達成率】。チーム成績は昇降格に影響しない。

| 項目 | 提案 | 意図 |
|---|---|---|
| 昇格 | **個人達成率110%以上を1期** → 1ランク昇格【2026-08-28 変更: 「100%以上×2期連続」ルートを廃止】 | 昇格は110%到達のみ。100〜109%の安定達成は現状維持（昇格には突き抜けが必要）。飛び級なし |
| 降格 | **個人達成率70%未満を1期** → **即1ランク降格**【2026-08-28 変更】 | 半年間の実績で判定は完結しており猶予は設けない（旧案の「2期連続」は廃止。労務リスクは社労士確認で担保） |
| 現状維持 | 上記以外 | **70〜109%のレンジのみ維持**（70%未満は即降格・110%以上は昇格） |

**用語の定義: 「1期」= 半期（6ヶ月）**。査定サイクルが半年（10〜3月 / 4〜9月）なので、期＝査定1回分。
2026-08-28以降、昇格・降格とも期をまたぐ条件（2期連続）は無くなり、**毎半期その期の個人達成率のみで判定が完結**する。

- 昇格すると翌期から月給と基準が同時に上がるため、「昇格直後は達成が難しくなる」のは仕様（次の段階への挑戦期間）
- ⚠️ 降格＝減給の運用は就業規則・賃金規程の裏付けが必須（社労士確認。旧制度からの持ち越し労務TODO）
