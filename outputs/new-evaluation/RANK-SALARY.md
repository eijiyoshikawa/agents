## 1. 超過達成ボーナス 段階制【2026-08-25 決定】

判定は**最終達成率**（チーム係数適用後）で行う。

| 最終達成率 | ボーナス |
|---|---|
| 100%以上 120%未満 | 月給 **1ヶ月** |
| 120%以上 150%未満 | 月給 **1.5ヶ月** |
| **150%以上** | 月給 **2ヶ月** |
| 100%未満 | なし |

- 支給は半期査定ごと（年2回）。年間最大 = 月給4ヶ月分
- 財務健全性: 150%達成者は半期基準の1.5倍の粗利（マーケなら776万）を生んでおり、追加0.5〜1ヶ月分（12.5〜25万）のコストは粗利の2〜3%に過ぎない。**段階が上がるほど会社の取り分も増える**ため財務中立以上
- チーム係数上限1.06の下では、150%到達に必要な個人達成率は最低141.5%（チーム120%時）

## 2. 月給テーブルの設計原則

1. **基準連動**: 月給が上がると粗利基準（×3 / 営業×3.5）も自動で上がる。昇給1万円 → 必要粗利は月+3.45万（営業は+4.03万）。**昇格者が基準を守る限り、昇給原資は本人の粗利増で賄われる**（昇給インフレが財務を毀損しない自己均衡構造）
2. 昇給幅は等差ベースで覚えやすく（+2万→+3万→+3万→+4万）。上位ほど幅を広げ、R5を「目指す価値のある頂点」にする
3. スタート位置は2案（→ #8 の決定と連動）

## 3.5 上限吐き出しシミュレーション（2026-08-25 追記・#8は案Bで決定）

「会社が最大限支払うケース」= 全員が最上位R5・全員が150%以上達成（2ヶ月×年2回）の場合。

|---|---:|---:|---:|---:|---:|

| マーケ / CA | 423万 | 460万 | 515万 | 570万 | **644万** |
| BPO統括 | 368万 | 405万 | 442万 | 497万 | **552万** |

### その支払いが発生する条件で本人が最低生んでいる年間粗利（150%×2半期）

| 職種 | R1 | R2 | R3 | R4 | R5 |
|---|---:|---:|---:|---:|---:|

### 組織全体の上限ケース（6名: 営業1・マーケ3・CA1・BPO1 全員R5・全員150%）

| 項目 | 金額/年 |
|---|---:|
| 給与（福利込み） | 2,898万 |
| ボーナス上限（4ヶ月×6名・福利込み） | 966万 |
| **上限人件費 合計** | **3,864万** |
| 会社実粗利の下限（両建て除去: マーケ3+CA+BPOのみ合算） | **10,557万** |
| **会社残り（間接費前）** | **+6,693万** |

参考: 全員ちょうど100%（1ヶ月×2回）の場合 → 人件費3,381万 vs 実粗利下限7,038万 → 残り+3,657万

**結論: この制度に「中間値」という概念はなく、上限吐き出しは常に財務最良のケース。**
ボーナスは粗利基準の達成に完全連動する後払いのため、支払額が最大になる状況＝粗利が最大の状況。
支払いだけ増えて粗利が付いてこないケースは構造上存在しない（基準連動＋段階制の帰結）。
会社が財務リスクを負っているのは固定部分（給与）だけであり、それは試算01（受注ペース下限）の話に帰着する。

## 4. 昇格・降格の閾値（#10 の提案）

| 項目 | 提案 | 意図 |
|---|---|---|
| 昇格 | **最終達成率110%以上を1期** または **100%以上を2期連続** → 1ランク昇格 | 一発の突き抜け or 安定達成の両ルート。飛び級なし |
| 降格 | **最終達成率70%未満を2期連続** → 1ランク降格 | 1期での即降格はしない（外部要因・案件端境期への耐性、労務リスク回避） |
| 現状維持 | 上記以外 | 70〜109%のレンジは維持。**70%未満でも1期目は維持**（2期連続で初めて降格） |

**用語の定義: 「1期」= 半期（6ヶ月）**。査定サイクルが半年（10〜3月 / 4〜9月）なので、期＝査定1回分。
「2期連続」= 1年間連続して該当した場合。

- 昇格すると翌期から月給と基準が同時に上がるため、「昇格直後は達成が難しくなる」のは仕様（次の段階への挑戦期間）
- ⚠️ 降格＝減給の運用は就業規則・賃金規程の裏付けが必須（社労士確認。旧制度からの持ち越し労務TODO）
