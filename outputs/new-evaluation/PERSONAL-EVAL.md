# 個人評価（昇格・降格ランク判定）— 役割配分方式【2026-09-07 統合・確定】

出典: 代表提供「LET 個人昇格評価シート」（2026-09-07版）を新評価制度へ統合したもの。
**補助指標（有効商談数・品質・期限遵守等の10点枠）は代表指示により不採用**とし、配点は主指標へ寄せて100点満点を維持した。
ボーナス（営業マーケ合同プール・粗利15%）とは独立（チーム賞与の成績を個人昇格の点数に混ぜない）。

> 本統合により、昇降格判定の旧方式（個人達成率＝個人粗利÷月給×1.15×経過月数×職種倍率、両建て100%計上）は**廃止**。
> 「月給×1.15×倍率」の配分前金額表は目標G・Nへ流用しない【シート明記】。

## 1. 本人評価粗利（役割配分方式）

```
本人評価粗利 = 当期認識粗利（売上 − 広告費・制作外注費等の直接外部原価）
             × 役割配分率（下表）
             × 役割内の本人担当割合
```

- 社員給与・会社負担保険料は個人評価粗利の控除対象にしない（会社利益の計算でのみ控除）
- 同じ外注費・広告費は二重控除しない。営業も受注時一括ではなく**当期粗利で統一**（受注総額は参考表示・前受入金は自動的に売上としない）

### 役割配分率（確定・ペア換算の中核）

| 事業・フェーズ | 役割配分 | 確定状況 |
|---|---|---|
| SNS初回契約期間 | **営業50%・マーケ50%** | 合意済み運用方針 |
| SNS更新後 | **営業10%・マーケ90%** | 代表指示（営業は更新アプローチ等を担当） |
| クロスセル単発（HP等） | 販売担当50%・制作納品担当50% | 代表承認済み |
| コミット型 | 営業20%・マーケ50%・CA30% | 初期値。正式採用を期首に確認 |
| 人材紹介 | RA50%・CA50% | 代表の従来方針 |
| BPO | BPO担当100% | 代表指示。別集計 |

### 帰属ルール

- 役員のみのAI案件、役員が担う営業分は社員に付けない。役員が紹介のみで社員が提案・契約を担う場合は営業内担当割合を事前登録。未担当分を社員へ自動付与しない（役員持分として残す）
- クロスセルの販売・納品を一人で完結すればその人100%。外注時も要件整理・外注管理・修正・納品確認を担う社員に納品分を付ける
- 既存SNSと追加契約（HP等）は**別案件IDで管理**し、元契約の配分を変更しない
- 同一案件の役割持分合計100%・各役割内の担当割合合計100%。異動・引継ぎは適用日以降の担当期間で処理（過去成果の付け替えなし）
- 返金・訂正は会計実績と整合した台帳へ記録。会社都合等による補正は会計粗利を改変せず理由・補正額を別記
- 粗利配分のない担当業務（人材紹介の集客・自社マーケ等）は、期首の工数割合に応じて主指標の一部を成果KPI（有効面談数等）に置き換える（主指標の内訳として管理。金額を持たない仕事を利益ゼロで低評価にしない・架空の内部売上は計上しない）

## 2. 半期目標G・Nと昇格用粗利ライン

```
事業計画の案件別・月別粗利 → 役割配分 → 役員分除外 → 本人担当割合
→ 対象月数・供給計画・工数・立ち上がり調整 → 現等級の半期目標G
次等級の想定担当範囲から同条件で 次等級目標N を設定

昇格用粗利ライン = max(G × 110%, N)
```

- Nを当該期に達成できる担当機会がない場合は期首に役割範囲を見直す（機会を与えず未達としない）
- 目標は期末に後付けで引き上げない。調整・変更は履歴（日付／理由／目標差額／本人説明）を残す
- 非金額の主指標を含む場合は、その配点で加重平均した主指標達成率110%以上＋次等級の担当成果要件で判定。コーポレートに架空の粗利ラインを課さない

## 3. 採点（補助指標なし・100点満点）

**定量＝主指標のみ**（補助指標1・2は不採用【2026-09-07 代表指示】。以下の配点は補助指標分を主指標へ振り替えて100点満点を維持した統合時の初期案。期首に確定・周知）:

| 職種 | 主指標（定量） | 定性: MVVに沿った行動 | 定性: チームへの貢献 | 合計 |
|---|---:|---:|---:|---:|
| 営業・CA | 本人配分後の当期粗利 **70点** | 20点 | 10点 | 100点 |
| マーケ・BPO | 本人配分後の当期粗利 **60点** | 25点 | 15点 | 100点 |
| コーポレート | 主要業務期限遵守 **60点** | 25点 | 15点 | 100点 |

- 主指標の得点 = 配点 ×（実績 ÷ 目標）、0〜配点に収める。昇格判定用に上限を掛ける前の達成率も保存
- 定性は観察項目を等配点: 期待以上＝100%／期待どおり＝80%／要改善＝40%。現等級の期待行動を基準に具体的事実で判定（性格・好感度・残業時間・担当売上の大小を根拠にしない。証拠未収集だけで要改善にしない）。判定フロー: 本人→上長→役員の基準確認→本人説明
- 観察項目: 約束・誠実な報告／顧客成果への対応／根拠のある改善（以上MVV）、情報・手順の共有／他者支援・引継ぎ・育成（以上チーム貢献）。正式MVVとの対応は期首に記入

## 4. 次等級の役割実証（直近3か月以上）

| 移行 | 必要な役割の証拠例 |
|---|---|
| R1→R2 | 標準業務を自立して期限・品質どおり遂行 |
| R2→R3 | 担当成果が安定し、他者が引き継げる情報・手順を整備 |
| R3→R4 | 支援・教育・改善で他者の品質や生産性も向上 |
| R4→R5 | 複数人で使える仕組みが定着し、チーム成果・品質が改善 |

- 部下の人数・役職ポストの空きを要件にしない。手順書は「他者が利用できたこと・改善効果」まで確認
- 自分しか触れない顧客情報・アカウントを抱える状態は上位の再現性要件を満たさない

## 5. 半期の昇格判定（全項目充足で1等級昇格・飛び級なし・等級内査定昇給なし）

| 確認項目 | 備考 |
|---|---|
| 主指標110%以上（粗利中心なら max(G×110%, N) 以上） | 補助指標廃止に伴い、旧様式の「定量全体の加重平均100%以上」条件は主指標に統合 |
| 総合評価80点以上（100点満点） | |
| 定性の全項目が期待どおり以上 | |
| 次等級役割を直近3か月以上実証 | |
| 原価・担当・対象期間に重大な未確定事項がない | 未確定の数字で昇格可否を確定しない |

- 総合点だけで自動判定しない。チーム賞与の成績を個人昇格の点数に混ぜない。会社都合で評価点を変えない。昇格費用は事前に予算へ反映
- **降格は昇格判定と別手続き**（昇格できないことを理由に降格しない）。降格基準は【統合時の暫定案】「本人評価粗利が G×70% 未満×1期で1ランク降格」として旧70%閾値をG基準へ読み替え — **期首確定事項**（社労士確認も本基準で実施）

## 6. 運用（月次確認・異議申立て）

- 月次で配分後粗利・供給条件・定性の事実・役割実証を確認（3ヶ月目に中間面談・6ヶ月目に半期確定）
- 本人は通知後10営業日以内に異議申立て、役員は20営業日以内に根拠付き回答（案）
- 休業・時短等は対象期間・稼働に応じて目標を調整（取得そのものを低評価にしない）

## 7. 運用開始前の入力残（施行の前提）

1. 各人のG・N の半期目標（配分後の事業計画・担当台帳から記入）
2. コミット型20:50:30の採用確認、担当・更新日・原価の台帳整備（案件ID・フェーズ〔SNS初回/更新後〕・担当割合の登録）
3. 正式MVVと具体行動の対応付け、閾値の期首確定・周知
4. ~~評価サイト・集計の改修~~ — **実装済み（2026-09-11）**: slack-let `lib/new-eval.js computeRoleEval` が台帳（フェーズ・担当割合）× 役割配分率 × G/N（MF連携設定 `neweval_targets`）で本人評価粗利と昇格ライン max(G×110%, N) を算出し、評価サイトの各メンバーカードに正式判定ゲージを表示する。台帳・Gが揃うまでは「判定準備中」と不足項目を表示（未入力をゼロ扱いしない）。旧分母ゲージは折りたたみの参考表示

未入力をゼロ扱いしない。ここまで埋まって初めて社員へ適用する個人別シートが完成する。
