Step 5 — 半期ボーナス設計（個人 × チーム連動）
// 半期ボーナス計算式
半期ボーナス = 基準額 × 個人達成率 × チーム係数

// 基準額（月給 × 2ヶ月）
G1 ジュニア : 300,000 × 2 = 600,000円（= 固定残業代を引いた金額 × 2ヶ月）
G2 スタンダード : 350,000 × 2 = 700,000円（= 固定残業代を引いた金額 × 2ヶ月）
G3 シニア : 400,000 × 2 = 800,000円（= 固定残業代を引いた金額 × 2ヶ月）
G4 マネージャー : 480,000 × 2 = 960,000円（= 固定残業代を引いた金額 × 2ヶ月）

// （固定残業代を引いた金額）が基準。ボーナス基準額は実質月給の2ヶ月分相当
// 個人達成率：半期粗利達成率をそのまま反映
// 定性評価はこのStepとは別で加味（Step 4の昇給連動に反映）
// 支給タイミング：上期＝9月末、下期＝3月末 ／ 支給月：10月・4月

Step 6 — 評価サイクル
毎月末
月次粗利レビュー
月次粗利の着地確認・必達ライン対比・ランク判定。マネージャーとの1on1（30分）でフィードバック。
3ヶ月目
中間評価
定量60点＋定性40点の中間スコアを確認。チーム達成率も共有し、ペースアップが必要なメンバーに早期介入。
6ヶ月ごと
半期評価・ボーナス支給
個人×チーム係数でボーナス算定。翌月（10月/4月）に支給。同時に基本給の昇降給とグレード審査を実施。
年1回
キャリア面談
G3→G4（マネージャー）志向か、スペシャリスト型で深化するかを本人と確認。翌年の目標設定へ接続。
