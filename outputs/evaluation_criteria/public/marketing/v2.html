Section 0 — 制度の基本思想
// 原則
業績（カネ）はチームで割り、格付け（ヒト）は個人で判断する

// 個人別の案件粗利は評価に使用しないが、計測は継続する
// （昇格・降格審査時の参考資料としてのみ開示）
Section 1 — 実質粗利の定義
実質粗利 = 売上 − （広告費 + 交通費 + 外注費 + その他案件実費）

// 社内人件費は差し引かない
// 新規/継続、案件タイプの区分なく全案件統一
1.1 月額リテーナー型計上ルール
毎月計上 毎月の請求額から当月実費を差し引き、当月粗利として計上。
標準案件例: 月額30万円 − 実費12.5万円（広告費9万 + 交通費0.5万 + 外注費3万）= 実質粗利17.5万円（粗利率58%）
1.2 コミット型（採用予算前受型）★v2.0新設計上ルール
前受金入金時粗利計上しない（預り金）
運用中の各月粗利計上しない（消化実費を管理するのみ）
採用決定月残額（100万 − 累計消化実費）を当月粗利として一括計上
予算枯渇・失注確定月粗利0円で案件クローズ
2人目の前受受領新規案件として同ルールを適用
✦ 構造: 採用1名分の予算100万円を前受けし広告運用で消化 → 採用決定で残額が粗利化。想定案件構成比: 月額型 50% : コミット型 50%。コミット型の平均決着期間: 6ヶ月以内 / 期待粗利: 約40〜50万円/件（仮置き。実績で更新すること）
Section 2 — チーム構成と役割定義
✦ 3名チーム。等級は役割と独立（どの役割からもM4まで昇格可能）。G4マネージャーはチーム外の将来枠。
Role 01
① 広告・求人担当
ペイド運用
  • 広告運用（Meta / Indeed / TikTok / LINE 等）、求人媒体運用
  • CPA・ROASの一次責任（運用実行・入札・配信調整の裁量）
  • コミット型案件の予算消化ペース管理・決着スピード責任
  • 運用実績データの③への連携
Role 02
② クリエイティブ担当
制作 + SNSオーガニック + 撮影品質責任
  • 広告クリエイティブ・LP・バナー制作
  • SNSアカウントのオーガニック運用・企画
  • 撮影計画・ショットリスト作成・素材品質基準の策定
  • 大型撮影（企画撮影・動画）の主導
  • ③が撮影した素材の検収（品質不足時の撮り直し指示権）
Role 03
③ アカウントディレクター
窓口 + 分析改善 + 撮影実行
  • クライアント窓口、レポーティング、進行管理
  • 継続率のオーナー（月額型案件の解約防止責任）
  • データ分析、改善提案の作成と顧客合意の取得
  • コミット型案件の進捗報告・期待値調整
  • 訪問時の撮影実行（②のショットリストに準拠。クリエイティブ判断は持たない）
  • 大型撮影時の現場調整（日程・クライアント側手配）
✦ 撮影の運用ルール: 撮影実務=③ / 企画・品質責任=②。撮り直し指示は ②→③ へショットリスト修正版として Notion 書面で出す（口頭指示不可）。修正履歴は役割遂行評価の判定材料として保存する。

// 昇格ルール
条件: A評価2期連続 + 昇格面談通過 → 翌期から等級改定
・昇格時、査定給はリセットし新等級給からスタート
・査定給上限+3万の設計により、昇格は常に実質プラス（最小でも+2万円）
・昇格に伴いチーム目標が自動増額 → 本人の実力とチームの受容力の両面で判断

// 降格ルール
審査条件: 個人評価50点（定性40+役割10）中25点未満が2期連続の場合のみ
・チーム定量不振（達成率C/D）を理由とする降格は行わない
・原則: チームが負けても個人は降格しない。役割を果たさない個人は、チームが勝っていても審査対象

Section 8 — 評価サイクル
毎月末
パイプラインレビュー
ランク判定の場ではない。半期累計進捗・コミット型パイプライン・解約予兆を確認 + マネージャー1on1（30分）。
隔週
ナレッジ共有会
AI活用事例・運用TIPS・失敗事例の共有。定性評価（Section 9）の判定材料。
6ヶ月ごと
半期評価
スコア確定・ボーナス支給・査定給改定・昇格/降格審査を一括実施。
年1回
キャリア面談
役割ローテーション・専門深化・M4/マネジメント志向の確認。
✦ 月次パイプラインレビュー必須項目: ①半期累計粗利の進捗率（3ヶ月経過で累計40%未満なら警告） ②コミット型パイプライン表（進行中件数/予算消化率/決着見込み月 — 消化率70%超で未決着は「粗利消失リスク案件」として個別対策発動） ③月額型の継続状況・解約予兆
✦ 事業側トリガー: チーム達成率がCランク帯（70%未満）で2四半期継続 → 案件ポートフォリオ（受注基準・案件ミックス）の見直しを実施
