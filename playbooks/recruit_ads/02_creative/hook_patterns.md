# フック・訴求パターン集

採用広告の冒頭1〜3秒で勝負を決めるフック集。**業種別 × ペルソナ別 × 媒体別**で使い分ける。

## 1. フックの基本5タイプ

| タイプ | 例 | 狙い |
|---|---|---|
| **数値型** | 「日給1.5万・週払い可」 | 即時の便益訴求 |
| **否定解消型** | 「夜勤なし・残業ほぼゼロ」 | ペルソナの痛みを否定 |
| **意外性型** | 「未経験40代女性が月収35万」 | スクロール手を止める |
| **共感型** | 「子供のお迎えに間に合う仕事」 | 当事者意識喚起 |
| **証言型** | 「入社3ヶ月の私が話します」 | 信頼性・親近感 |

## 3. ペルソナ別フック軸

| ペルソナ | 最優先軸 | 第2軸 |
|---|---|---|
| 主婦パート（30-50女性） | 時間融通・子供との両立 | 給与・職場の雰囲気 |
| シニア（55-70） | 体力配慮・短時間 | 健康維持・社会参加 |
| 学生（18-22） | シフト融通・まかない | 仲間・楽しさ |
| フリーター（20-30） | 即金性・週払い | 正社員登用・スキル習得 |
| キャリア転職（30-45） | 年収・残業・休日 | 成長機会・経営層との距離 |
| シングルマザー（25-45） | 子供優先のシフト | 安定性・福利厚生 |

## 4. NGフック（職業安定法・男女雇用機会均等法）

以下は使用禁止。Legal Agent の事前チェック必須。

- 「明るい人」「元気な女性」等の主観・性別限定（要件あれば例外）
- 「20-30代活躍中」等の年齢限定（例外要件外）
- 「絶対稼げる」「100%採用」等の断定
- 「No.1」「業界一」等の出典なし優位表現
- 競合誹謗（「○○社より高い」等）

## 5. フックの検証方法

1本のクリエイティブで複数フックをABテスト。
- Hook率（3秒視聴率）で初期評価
- CTR・CVR・有効応募率まで追って総合判定
- 勝ちフック → `06_formulas/` に方程式として登録
- 負けフック → 理由を記録（ペルソナミスマッチ等）

## 6. 新フック発見の手順

1. 既存顧客（採用済み社員）に「応募の決め手」をヒアリング（5-10人）
2. 競合の広告ライブラリ（Meta Ad Library / TikTok Creative Center）を週次でウォッチ
3. SNS上の「○○の仕事ってどう？」系投稿のコメント欄を観察
4. 候補3-5本を作成 → Phase1探索で同時テスト
5. 勝ちフックを本ファイルに追記
