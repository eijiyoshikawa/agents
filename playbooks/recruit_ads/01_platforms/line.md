# LINE広告ガイド

国内リーチ最大級。30-60代主婦・シニア層に強い。介護・建設・運輸・パート求人で有効。

## 1. 強みと弱み

**強み**
- 国内アクティブユーザー 9000万人超、年齢層が幅広い（特に40-60代）
- LINEトーク・タイムライン・LINE NEWS等の純広告配信
- LINE公式アカウント友だち追加 → 継続接触 → 応募導線が組める
- 主婦・シニア層へのリーチでは Meta より優れる

**弱み**
- CTR が他媒体より低い（0.5-1.5%）
- クリエイティブ仕様が厳しい（テキスト面積制限・表現規制）
- ターゲティング精度は Meta に劣る
- 動画広告の効果は Meta/TikTok 比で限定的

## 2. 推奨キャンペーン構成

### A. 公式アカウント友だち追加→応募（推奨）

```
Campaign: 友だち追加目的
  └ Ad Group: 1〜3本
        └ Ad: 静止画 or 動画
              ↓ 友だち追加
        LINE公式アカウント
              ↓ 自動応答 / リッチメニュー
        応募フォーム（LIFF or LP）
```

→ 直接応募より**1ステップ多い**が、離脱者にもリマインド送れる。**有効応募率が高い**。

### B. 直接LP誘導（Web Conversion）

```
Campaign: ウェブサイト誘導 / コンバージョン
  └ Ad Group: ターゲティング軸で分離
        └ Ad: 静止画 / カルーセル / 動画
              ↓ Click
        LP → フォーム → 応募
```

CPCは Meta より低めだが、CVRも低い傾向。総CPAでは中庸。

## 3. クリエイティブ仕様

| 形式 | 仕様 |
|---|---|
| Card画像 | 1200x628 / テキスト面積20%以下推奨 |
| Square画像 | 1080x1080 |
| 動画 | 9:16 or 1:1 / 5-60秒 / 自動再生（音なし前提） |
| カルーセル | 3-10枚 |

### 表現規制（注意）

- 過度に煽る表現NG（「絶対」「日給10万!!」等）
- 比較広告NG
- 「No.1」表記は出典明記必須
- 募集要項は職業安定法準拠（年齢・性別限定は例外要件のみ）

## 4. ターゲティング

| 軸 | 設定 |
|---|---|
| 年齢 | 業種特性で（介護: 35-60 / 建設: 25-50 / 主婦パート: 30-50 女性） |
| エリア | 都道府県・市区町村単位 |
| みなし属性 | 興味関心・購買行動（LINEショッピング由来） |
| オーディエンス | IDFAなしで類似拡張可能（独自データ） |
| 友だち除外 | 既存友だちを除外して新規獲得効率化 |

## 5. 公式アカウント運用との連携

LINE は単体広告より「広告 → 公式アカウント → 応募」の流れで真価。

- **リッチメニュー**: 「応募する」「シフト相談」「Q&A」等のCTA配置
- **自動応答**: キーワード「応募」「面接」で即対応
- **ステップ配信**: 友だち追加から1日後・3日後・7日後にリマインド
- **LIFFアプリ**: フォームをLINE内で完結 → 離脱削減

## 6. 計測

- LINE Tag を LP に設置
- LINE公式アカウント友だち追加 → API Webhook で CRM 連携
- 応募までを `friend_added_at` → `applied_at` で trace
- CAPI 相当（Conversion API）2026年時点で順次提供 → 設定推奨

## 7. クリエイティブテンプレ（採用向け）

| パターン | 構成 | 業種適性 |
|---|---|---|
| **主婦応援型** | 「家事と両立できる○○の仕事」 | パート・介護・保育・販売 |
| **シニア応援型** | 「60代から始める〇〇」 | 警備・清掃・運転 |
| **未経験安心型** | 「研修○ヶ月で活躍中」 | 介護・運輸・製造 |
| **収入訴求型** | 「Wワーク歓迎・夜だけOK」 | 飲食・配送 |
| **地域密着型** | 「○○駅近くで募集」 | 全業種、特にパート |

## 8. よくある失敗

- [ ] 画像内テキスト過多で配信制限
- [ ] 動画依存（LINE は静止画+短尺で十分）
- [ ] 公式アカウント未設置で直LP誘導のみ
- [ ] 友だち追加後の自動応答未設定で離脱
- [ ] Meta CRTV をそのまま流用（雰囲気が合わない）
