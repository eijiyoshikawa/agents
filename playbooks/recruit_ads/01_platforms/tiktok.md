# TikTok For Business 広告ガイド

採用広告における TikTok の使い方。若年層・拡散性に強み。

## 1. 強みと弱み

**強み**
- 10-30代リーチ最大級。飲食・美容・接客・販売・コールセンター系で強い
- UGC風クリエイティブで圧倒的にCPM安い
- 拡散性が高くオーガニックも狙える（オーガニック→広告のセット運用）

**弱み**
- 計測精度が Meta より劣る（CV計測の遅延・欠損）
- 応募ジャンクが多く、有効応募率が落ちやすい
- 30代後半以上のリーチは弱い（介護・建設には不向き）
- クリエイティブ寿命が短い（1-2週間で疲弊）

## 2. 推奨キャンペーン構成

### A. CV最適化（Web応募）

```
Campaign: Website Conversions
  └ Ad Group: 1〜3本
        ├ Smart Audience（自動）優先
        ├ エリア: 都道府県 + 半径指定（Metaより粒度粗い）
        ├ 配置: TikTok / Top Buzz / Pangle（Pangleは品質次第でOFF）
        ├ 予算: 日予算 5,000〜15,000円/Ad Group
        └ 入札: Lowest Cost → CV溜まり次第 Cost Cap へ
              Ad: 5〜10本（CRTV多めに投入、寿命対策）
```

### B. Lead Generation（インスタント応募）

Meta同様、CVRは高いが品質下がる。**有効応募CPA で評価**。

### C. Spark Ads（オーガニック投稿の広告化）

自社 or インフルエンサーの実投稿を広告化。**最も再現性高い**。

## 3. クリエイティブ仕様

| 形式 | 仕様 | 用途 |
|---|---|---|
| 縦動画 | 9:16 / 9-30秒 / 字幕必須 / BGM必須 | メイン |
| Spark Ads | 既存投稿の Authorization Code 取得 | 実体感・拡散性 |
| カルーセル | 静止画 2-35枚 | 限定的（CTR低い） |

### 重要原則

- **TikTok感を保つ**: 広告っぽさを排除（プロ動画より素人感が勝つ）
- **1秒目に動き**: 静止画的なオープニング = スキップ確定
- **テロップ占有率 30-50%**: 無音視聴前提
- **BGM**: 商用OKトラックから選定（音商標違反注意）
- **ハッシュタグ**: 業種・エリア・トレンドを混在

## 4. クリエイティブテンプレ（採用向け）

| パターン | 構成 | 業種適性 |
|---|---|---|
| **1日密着** | 「〇〇歳、〇〇職の私の1日」 | 全般、特に介護・保育・看護 |
| **給与公開** | 「月給○○万円もらってます」 | 運輸・建設・営業 |
| **入社理由** | 「未経験から○○ヶ月でこうなった」 | IT・営業・美容 |
| **職場ツアー** | 「うちの会社こんな感じ」 | 飲食・美容・小売 |
| **失敗→克服** | 「最初は失敗ばかりだったけど…」 | 営業・接客全般 |
| **Q&A** | 「よく聞かれる質問に答えます」 | 全般 |

詳細フック集: `02_creative/hook_patterns.md`

## 5. ターゲティング

| 軸 | 設定例 |
|---|---|
| 年齢 | 18-34 メイン、35-44 サブ |
| エリア | 都道府県 or 主要市区 |
| 興味関心 | 業種関連 + ライフスタイル（料理・育児・車・ゲーム等） |
| Hashtag/Creator Interaction | 同業界フォロワー・視聴者 |

## 6. 計測（重要）

- **TikTok Pixel + Events API（CAPI 相当）** 両方設定必須
- Self-Attributing Network（SAN）レポートの数字と GA4 の数字は乖離する → **両方追う**
- 14日CV ウィンドウを基本に
- LP側で `ttclid` を取得・保存（後段の有効応募率・CPHトラッキングに使う）

## 7. 学習期間

| 期間 | アクション |
|---|---|
| Day 0-2 | 触らない |
| Day 3-5 | 低CTR Ad停止、新弾投入 |
| Day 6-10 | 勝ち弾の予算引き上げ、Cost Cap適用 |
| Day 10+ | クリエイティブ疲弊監視、週次で30%入れ替え |

## 8. よくある失敗

- [ ] Meta用横長動画をそのまま流用（縦動画必須）
- [ ] BGMなし配信（再生されない）
- [ ] CRTVを週1ペースでしか入れない（疲弊速度に追いつかない）
- [ ] Pangle配信を絞らない（品質低い流入で有効応募率激落）
- [ ] 計測がPixelのみでCAPI未設定（CV過小評価）
