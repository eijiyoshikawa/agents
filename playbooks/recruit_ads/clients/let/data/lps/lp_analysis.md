| 要素 | 内容 |

### LP-A の印象
- **ストーリーで引き込む型**。社会課題→ソリューション→実績→人 と流す
- **数字訴求が厚い**（500万人・260%・-92%・95%定着）
- 「LINEで応募 1分で完了」を強調

- 「キャリアパス」が独立セクションで強調

## 4. 法人セールス（コーポレートセールス）視点での評価

### 共通課題
- **両LPとも法人セールス専用ではない**。SNSマーケ職が前面に出る構成
- 詳細な「コーポレートセールス」業務内容・要件・1日スケジュールは**LP内では限定的**
- 法人セールス志望者が来た場合、「SNSマーケ会社が片手間で営業も募集してる」と誤解する可能性

### LP-A の強み（コーポレートセールス向き度）
- ストーリーで引き込む → 「LETという会社」を理解させる力強い
- 数字訴求が厚い → セールス志望者の数字センスに訴求可
- マーケ実績 (-92%/+260%) は **法人営業先での提案材料としても魅力的**

### LP-B の強み
- ROLE 並列構造 → 「コーポレートセールスの仕事」をスッキリ理解させやすい
- COMMON CONDITIONS が独立 → 待遇比較が見やすい
- インタビュー2人 → 「人」で判断する層に強い

## 5. 訴求軸 vs LP マッピング（改訂版）

Phase 1 戦略で立てた4訴求軸を、両LPの実コンテンツに照合:

| 訴求軸 | LP-A 適性 | LP-B 適性 | 推奨 |
|---|---|---|---|
| H1 給与「年収400万スタート」 | ◯（数字訴求文脈と整合） | ○（COMMON CONDITIONS で明示） | 両LP使用可。**ただし月給25-30万＋賞与なので、年収訴求は注意**。「年収例 380-440万」が安全 |
| H2 成長「未経験から3年で主力」 | ◎（キャリアパス強調） | ◎（CAREER PATH 独立セクション） | 両LP使用可、**LP-B**やや強い |
| H3 裁量「若手から意見が通る」 | ◯（CULTURE「裁量権のある環境」明記） | ◯（同上） | 両LP使用可 |
| H4 働き方「中央区・残業少・私服OK」 | △（**リモート不可・出張あり**） | △（同上） | **要修正**: 「リモート不可」「出張あり」「対面重視」は事前提示推奨 |
| **NEW H5 社会課題・ビジョン** | ◎（メインキャッチそのもの） | ◎（同上） | 両LP使用可、**LET核となる訴求軸**として追加 |
| **NEW H6 スピード入社「最短2週間」** | ○（FLOW明記） | ◎（5ステップ明記） | 両LP使用可、即決層に刺さる |

### 重要修正
- **H4 働き方訴求は危険**: LP実態と齟齬（リモート不可・出張あり・対面重視）。配信する場合は「対面・スピード重視のチームで成長したい人へ」など言い換えが必要
- **H5 社会課題訴求を追加**: 「建設業を、AIで変える」は LET の核。志高い層・社会貢献志向に強く効く
- **H6 スピード入社訴求を追加**: 「現職に違和感、すぐ動きたい」層に効く

## 6. LP振り分け（推奨）

| CRTV訴求 | 推奨LP | 理由 |
|---|---|---|
| H1 給与・年収 | LP-A | 数字訴求の文脈で給与が腑に落ちる |
| H2 成長・キャリア | LP-B | CAREER PATH 独立セクションで完結性高い |
| H3 裁量 | LP-A | CULTURE「裁量権のある環境」のストーリー強い |
| H5 社会課題・ビジョン | LP-A | 業界課題ストーリー→ソリューションの導線が強烈 |
| H6 スピード入社 | LP-B | 選考フロー5ステップが明示的、CTAも分かりやすい |

→ 各CRTV にメッセージマッチで LP-A or B を割当て、**LP差は副次変数として A/B 計測**。

### 影響と対策

**未設置のままで配信した場合**:
- Meta/TikTok/LINE Ads の媒体側CV計測がゼロ → 最適化が応募ジャンクや偶発訪問者に向かう
- Offline Conversion 連携不可 → 「採用」「定着」へ最適化できない、応募止まりの最適化
- ROAS / CPA の正確な評価不能 → 方程式化に到達しない

**配信前タスク（Engineer 担当）**:
1. **GTM コンテナを新規作成**（LP-A / LP-B 共通で1つにまとめる推奨）
2. GTM 経由で Meta Pixel / TikTok Pixel / LINE Tag を埋め込み
3. GA4 を統合（できれば LP-A / LP-B を同一プロパティに移行 or GA4 BQ Export で横断集計）
4. CV イベント定義: `PageView` / `ScrollDepth_50` / `LineFriendClick`（LINE誘導ボタンタップ）
5. LINE 友だち追加後の `Lead` イベント（LINE 側 Webhook → CAPI 連携）
6. CAPI（Meta Conversions API / TikTok Events API）でサーバーサイド送信

詳細手順は `04_measurement/tracking_setup.md` 参照。

## 8. 配信前の重要修正事項

1. **法人セールス専用セクションへのアンカーリンク**: CRTVから来た人が直接 `#corporate-sales` 等のセクションに飛ぶよう URL を設計
2. **法人セールスの募集要項詳細をLPに追記要望**（必須要件・歓迎要件・1日スケジュール）
3. **「リモート不可・出張あり」をCRTVで前置き** — 応募ジャンク削減
4. **給与表記**: 「年収400万〜」を使う場合は内訳明示推奨（労基法+Meta規約配慮）
5. **応募導線**: LINE一本化なので、CRTV→LP→LINE友だち追加→自動応答→応募完了 のステップ毎にイベント計測必要
