## 2. 仮説（H-statement）
H-EXP-20260525-001:
大阪市中央区の法人セールス求人 × P-eigyo-01（異業種転職25-35）に対し、
TikTok広告で訴求軸を [給与 / 成長 / 裁量 / 働き方] の4種で比較すると、
**裁量訴求（H3）** が CTR・CVR ともに最高となる。
理由: 同ペルソナの転職動機調査一般論として、給与 < 成長 < 裁量の優先順位が
若手異業種転職層で見られる（ペルソナ仮説、実検証必要）。

| H4 働き方訴求 | 「大阪中央区・残業少・私服OK」（要確認） |

## 4. 成功基準
- 主指標: CTR (媒体側) + LP→Apply CVR
- 期待差: 最強軸が最弱軸の +30%以上
- サンプル: 各訴求 imp 3,000以上、クリック 50以上
- 統計: 二項検定 p < 0.1（探索フェーズ基準）

注: 月3万円ではサンプル不足の可能性高。**Phase 1は方向性把握が目的**、確定検証は次サイクル。

## 5. キャンペーン構成

```
Campaign: tt_eigyo_osaka-city_cv_202606_001
  ├ Ad Group: smart-audience_h1-salary_m
  │   ├ Ad: ugc_c001_a (社員A給与)
  │   └ Ad: text_c004_a (テロップ給与)
  ├ Ad Group: smart-audience_h2-growth_m
  │   ├ Ad: ugc_c002_a (社員B成長)
  │   └ Ad: text_c005_a (テロップ成長)
  ├ Ad Group: smart-audience_h3-saryou_m
  │   ├ Ad: ugc_c003_a (社員C裁量)
  │   └ Ad: text_c006_a (テロップ裁量)
  └ Ad Group: smart-audience_h4-hatakikata_m
      └ Ad: text_c007_a (テロップ働き方)
```

各 Ad Group 日予算 250-300円。学習促進のため初週は Lowest Cost、2週目から Cost Cap。

## 6. クリエイティブ
- c001-c003: 社員顔出しUGC（撮影協力可な場合）
- c004-c007: テロップ動画（社員不在でも制作可）
- 全本 縦9:16 / 字幕焼き込み必須 / BGM必須 / 15-30秒

→ LP URL 受領後にマッピング再確認。
