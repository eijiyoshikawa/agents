# KPI 定義集

採用広告で**全媒体・全業種で同じ定義**を使うためのKPI辞書。集計時に定義が揺れると比較不能になる。

## 1. ファネル全体

```
Impression（表示）
  ↓ CTR
Click（クリック）
  ↓ LP到達率
LP Session
  ↓ フォーム開始率
Form Start
  ↓ フォーム完了率
Apply（応募）
  ↓ 有効応募率
Valid Apply（有効応募）
  ↓ 連絡到達率
Reachable
  ↓ 面接設定率
Interview
  ↓ 面接実施率
Interviewed
  ↓ 内定率
Offer
  ↓ 承諾率
Hire（採用）
  ↓ 定着率（90日）
Retained
```

## 2. 基本KPI（媒体側）

| KPI | 定義 | 計算式 | 目標レンジ目安 |
|---|---|---|---|
| **CPM** | 1000imp あたり費用 | `cost / imp * 1000` | 媒体・業種で変動 |
| **CTR** | クリック率 | `click / imp` | Meta: 1.5-3% / TikTok: 2-5% / LINE: 0.5-1.5% |
| **CPC** | クリック単価 | `cost / click` | 業種で変動 |
| **CVR (lp→apply)** | LP→応募の転換率 | `apply / lp_session` | 3-15%（業種依存大） |
| **CPA (apply)** | 応募1件あたり費用 | `cost / apply` | 後述（業種別目安） |

## 3. 採用ファネルKPI（重要）

媒体CPAだけ追うと「応募ジャンク」が混入するため、**有効応募CPA / 採用CPA まで必ず追う**。

| KPI | 定義 |
|---|---|
| **有効応募率** | `valid_apply / apply` ※ 連絡可能・要件満たす応募の割合 |
| **CPA (valid)** | `cost / valid_apply` |
| **連絡到達率** | `reachable / valid_apply` |
| **面接設定率** | `interview_scheduled / reachable` |
| **面接実施率** | `interviewed / interview_scheduled` |
| **内定率** | `offer / interviewed` |
| **承諾率** | `hire / offer` |
| **CPH (Cost Per Hire)** | `cost / hire` ← **最終KPI** |
| **90日定着率** | `retained_90d / hire` |
| **CPRH (Cost Per Retained Hire)** | `cost / retained_90d` ← **真の最終KPI** |

## 4. クリエイティブ評価KPI

| KPI | 定義 | 用途 |
|---|---|---|
| **Hook率** | 3秒視聴率（動画） | フックの強さ評価 |
| **View率** | 完視聴率 | 訴求の説得力評価 |
| **Save / Share率** | 保存・シェア率 | バイラル可能性 |
| **Comment Sentiment** | コメントのポジ/ネガ比 | 炎上リスク検知 |

## 6. 媒体特性メモ

| 媒体 | 強み | 弱み | 適した業種 |
|---|---|---|---|
| Meta (FB/IG) | ターゲ精度・データ厚 | CPM上昇傾向 | 全業種、特に30-50代 |
| TikTok | 若年層リーチ・拡散性 | 計測精度・ジャンク多 | 飲食・美容・10-20代向け |
| LINE | 国内リーチ最大・年齢上 | CTR低・CRTV制約 | 介護・建設・主婦パート |
| YouTube | 視聴維持・ブランド | 制作コスト高 | 採用ブランディング |
| X | 拡散性・ニッチ | 採用CV弱い | IT・クリエイティブ |
| Indeed/求人媒体 | 顕在層 | 競合多 | 全業種（ベース） |

## 7. 集計の単位

| 単位 | 用途 | 集計頻度 |
|---|---|---|
| Ad 単位 | クリエイティブ評価 | 日次 |
| Ad Set 単位 | ターゲ・訴求評価 | 日次 |
| Campaign 単位 | 媒体・業種・エリア評価 | 週次 |
| EXP-ID 単位 | 仮説検証 | 終了時 + 週次中間 |
| 業種 × エリア | 方程式更新 | 月次 |

## 8. アラート閾値

KPI Dashboard が日次でチェック・通知する基準。

- 応募CPA が直近7日平均の **1.5倍** → 黄色アラート
- 応募CPA が直近7日平均の **2.0倍** → 赤色（自動停止検討）
- CTR が直近7日平均の **0.5倍以下** → クリエイティブ疲弊疑い
- 有効応募率 が **30%未満** → ターゲ or 訴求のズレ疑い
- 予算消化率が **120%超** → Ad Ops即対応
