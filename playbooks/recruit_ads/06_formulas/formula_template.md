# 方程式テンプレート（F-{area}-{industry}）

エリア × 業種 ごとに「再現性ある勝ち筋」を方程式化したもの。
**confidence ≥ 0.7 のインスティンクトが3つ以上集まったら作成**。

ファイル名: `formulas/F-{area_code}-{industry_code}.md`
例: `formulas/F-saitama-south-kaigo.md`

---

```markdown
# F-saitama-south-kaigo: 介護 × 埼玉県南エリア 採用広告方程式

## バージョン
- v1.0 / 2026-08-15
- 寄与実験: EXP-20260601-003, EXP-20260620-007, EXP-20260710-012 (計3本)
- 寄与インスティンクト: RA-001, RA-005, RA-008

## 適用条件

| 条件 | 値 |
|---|---|
| 業種 | 介護（kaigo） |
| エリア | saitama-south（さいたま・川口・戸田・蕨・所沢） |
| 雇用形態 | パート / 正社員 |
| ペルソナ | P-kaigo-01（主婦パート希望30-50女性） |

異なるエリア・雇用形態では再検証必須。

## 推奨構成

### 媒体配分

| 媒体 | 配分 | 理由 |
|---|---|---|
| Meta | 60% | 30-50代女性に強い、CPA最安 |
| LINE | 30% | 主婦層に強い、補完的 |
| TikTok | 10% | 認知補助、CPHは劣る |
| Indeed | 別予算（オーガニック+有料） | ベースライン |

### ターゲティング

- 年齢: 30-50
- 性別: 女性（職業安定法上の例外要件確認）
- 半径: radius-10km-{駅 or 事業所}
- 興味関心: Advantage+ 任せ
- 除外: 既存応募者

### 訴求（強い順）

1. **夜勤なし日勤のみ**（最強、CVR平均6.5%）
2. **シフト2日前まで変更OK**（次点、子育て層に強い）
3. **未経験OK・資格取得支援**（補助）
4. ❌ 給与訴求単独（このペルソナでは弱い）

### クリエイティブ

- 形式: UGC動画 9:16 / 30秒以内
- 出演: 30-40代女性（在籍社員のリアル撮影 推奨）
- 字幕: 必須（無音視聴対応）
- フック1秒目: 「夜勤なし」テロップ大きく

### LP

- `lp-kaigo-v2-short` を基準
- FV動的切り替え（utm_content連動）
- フォーム4項目以内
- スマホ電話タップCTAを併設

### 予算

- 月額目安: 30-100万円
- Ad Set あたり日予算: 3,000-8,000円
- 1Ad Setあたり週50CV確保

## 失敗パターン（このセグメントで踏むな）

- [ ] 給与訴求単独で配信（CVR半減）
- [ ] 男性訴求のCRTV使用（共感されず）
- [ ] 半径20km超え（通勤距離超過で応募取消）
- [ ] 夜勤シフトを含む求人で配信（言行不一致で炎上＆早期退職）
```

## 方程式昇格基準

| 段階 | 条件 |
|---|---|
| **インスティンクト登録** | 1実験で発見、confidence 0.3 |
| **インスティンクト確立** | 3実験で再現、confidence 0.7+ |
| **方程式 v1.0** | 異なる時期・出演者・LP で再現、3インスティンクト集積 |
| **方程式 v2.0** | 10実験以上の蓄積、別エリアでも一部適用可 |
| **CLAUDE.md ルール昇格** | 全社で再現性確認、運用基準として固定 |

## 方程式の使い方（quickstart.md からの参照）

新規案件で「介護×埼玉南」を担当 → `formulas/F-saitama-south-kaigo.md` をベースに
キャンペーン構成・予算・CRTV方針・LPを決定。完全コピペで始められる状態にする。
