# xpro X コンテンツカレンダー（1ヶ月目テンプレート）

## 運用方針

- **投稿頻度:** 1日 2-3 投稿（xpro 自体で自動運用）
- **投稿時間帯:** 7:30 / 12:15 / 20:00（エンゲージメント高い時間帯）
- **公式アカウントの位置づけ:** xpro 自体を xpro で運用する「ショーケース」
- **末尾署名:** 投稿末尾に `#xpro` を必ず付与

## 月次レビューチェックリスト

毎月末に以下を確認し、翌月のカレンダーを調整:

- [ ] フォロワー増減数（目標 vs 実績）
- [ ] 投稿カテゴリ別のインプレッション平均
- [ ] 最もエンゲージメントが高かった投稿 TOP3 → 翌月に類似投稿を増やす
- [ ] 最もエンゲージメントが低かった投稿 → 原因分析し改善 or 削減
- [ ] サイト流入数（X 経由）
- [ ] 無料トライアル登録数
- [ ] 投稿時間帯ごとのエンゲージメント比較 → 最適時間帯の調整
