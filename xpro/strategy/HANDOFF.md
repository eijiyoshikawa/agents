# xpro コンテンツ戦略 引き継ぎプロンプト

## プロジェクト概要
xpro（https://xpro.skma.asia/）はサブスクモデルのX（Twitter）自動運用SaaSツール。
サービスサイトのコンテンツを戦略から設計し、集客〜コンバージョンまでを一貫して構築する。

## サービス情報

### 料金プラン
| | ミニマム | スタンダード | プロ |
|---|---|---|---|
| 月額 | ¥980 | ¥1,980 | ¥3,480 |
| AI自動投稿 | 月30件 | 月50件 | 月50件 |
| Xアカウント | 1つ | 1つ | 3つ |
| スケジュール | 固定時間のみ | 日付+時間 | 自由スケジュール |
| AIトーン | 2種（プロ/カジュアル） | 3種（+教育的） | カスタムトーン入力 |
| レポート | - | 基本レポート | 詳細+CSV出力 |
| サポート | - | メール | 優先メール |
| 無料期間 | 1ヶ月半 | 1ヶ月半 | 1ヶ月半 |
| 解約 | いつでもOK | いつでもOK | いつでもOK |

### 差別化ポイント（vs競合）
- 価格破壊: ミニマム¥980はSocialDog（¥1,480〜）より33%安い
- 長期無料体験: 1ヶ月半（競合は7〜14日が主流）
- AIトーン選択: カジュアル/プロ/教育的/カスタムと段階的に選べる
- いつでも解約OK: 縛りなしで稟議が通りやすい
- プロプランで3アカウント対応

### 競合環境
- SocialDog: 月額¥1,480〜、100万アカウント超、日本市場リーダー、AI文章生成なし、無料7日
- PostManager: 月額¥1,980〜、複数SNS対応、AI限定的、無料7日
- Statusbrew: 月額¥15,000〜、大規模組織向け、年契約中心、無料14日
- Buffer/Hootsuite: 海外勢、日本語サポート限定的
- 市場規模: SNS運用支援283億円（2024）→690億円（2029予測）、年率約10%成長

## ターゲットペルソナ

### ペルソナ1: 個人クリエイター / インフルエンサー志望層 → ミニマム（¥980）
- 20-35歳、副業・フリーランス
- 課題: 投稿ネタを考える時間がない、投稿不定期でフォロワー伸びない
- メッセージ: 「1日約33円でX運用が自動化。スタバ1杯分で1ヶ月の投稿を自動生成。」

### ペルソナ2: 中小企業マーケ担当 / 一人マーケター → スタンダード（¥1,980）
- 25-45歳、従業員5-50名企業
- 課題: SNS運用に時間取れない、外注月10万円以上
- メッセージ: 「SNS運用外注: 月10万円 → xpro: 月¥1,980。年間117万円の削減。」

### ペルソナ3: 副業・スモールビジネスオーナー → ミニマム→スタンダードへアップセル
- 30-50歳、EC・コーチング・教室運営等
- 課題: 何を投稿すればいいかわからない
- メッセージ: 「何を書けばいいかわからない？AIが考えます。まずは1ヶ月半、無料で。」

## 決定済みの戦略（3パターン）

### P1「Show, Don't Tell」自社運用公開戦略（最優先・即日開始）
- xpro公式アカウント自体をxproで運用しショーケースにする
- 1日2-3投稿（運用レポート/Tips/ビフォーアフター/機能紹介）
- コストほぼゼロ

### P2「Seed & Spread」インフルエンサー種まき戦略（1ヶ月目後半から並列）
- マイクロインフルエンサー20-30名に3ヶ月無料提供→口コミ拡散
- 2ヶ月目〜「#xproで変わったこと」UGCキャンペーン

### P3「Educate to Convert」教育型コンバージョン戦略（2ヶ月目から投入）
- X運用ノウハウを発信しブランド構築→コンバージョン
- スレッド戦略+ブログ記事（月2-4本、SEO狙い）

### 実行ロードマップ（リソース: 1-2名・週10時間）
- 1ヶ月目前半: P1(7h) + P2リストアップ(3h)
- 1ヶ月目後半: P1(4h) + P2 DM・交渉(6h)
- 2ヶ月目: P1(3h) + P2(4h) + P3(3h)
- 3ヶ月目: P1(2h) + P2(3h) + P3(5h) → データで注力パターン選定

## LP構成（決定済み）
1. ヒーロー「あなたのX、AIが毎日育てます。」+ CTA「1ヶ月半無料で始める」
2. 課題共感「こんな悩み、ありませんか？」（4つの課題カード）
3. ソリューション「xproがすべて解決」（AIトーン/スケジュール/完全自動）
4. 使い方3ステップ（登録→設定→自動運用）
5. 競合比較表（xpro vs SocialDog vs 運用外注）
6. 料金プラン（3プラン横並び、スタンダードに人気No.1バッジ）
7. 実績・ユーザーの声（運用データ蓄積後に追加）
8. FAQ（6問）
9. 最終CTA「リスクゼロ。1ヶ月半試して、合わなければ即解約。」
