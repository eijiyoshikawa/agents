「本当にうまくいく？」あえて厳しくチェック

1. 対象を絞りすぎて人が集まらないかも？

心配なこと：「30代以上×経験者限定」だと、そもそも来てくれる人がいるのか？

最悪の場合：推計3,000〜5,000人いても、実際に動く人はその5〜10%（150〜500人）かもしれない。

対策：初月は無料体験会を3回やって反応を見る。5人集まらなければ「25歳以上」に条件を広げる。

2. 低価格の逆効果

リスク：1,000円が「質が低い」シグナルに。経験者ほど「安かろう悪かろう」を警戒。

対策：安さの理由を明示。将来1,500円への値上げ余地を設計に組み込む。当日無断キャンセル3回で参加お断りルール。

3. Instagramだけで30代以上に届くの？

心配なこと：Instagramのダンス動画は若い子向けが多く、30代以上はGoogle検索や口コミで探す人が多い。

対策：Instagramだけに頼らず、ジモティー・ストアカ・Googleマップにも情報を出す。複数の入口を用意する。

4. 1人運営の持続性

リスク：レッスン・SNS運用・予約管理・会計を1人で回す燃え尽きリスク。

対策：月2回スタートで負荷検証。予約はGoogleフォーム、会計はfreee無料プランで自動化。

5. コミュニティの内輪化

リスク：少人数が仲良くなりすぎて新規参入しにくい雰囲気に。

対策：月1回のオープンクラスと友達紹介特典で新規流入を仕組み化。

6. レンタルスタジオの安定確保

リスク：格安スタジオは人気が高く、毎週同じ条件確保が困難。場所が変わると離脱の原因に。

対策：候補3箇所以上リストアップ。定期利用契約があるスタジオを優先。LINEで毎回情報共有。

この事業で本当に大事なこと

  1. 大事なのは「レッスンを開く」ことじゃなく「30代以上の経験者が同世代と踊れる居場所を作る」こと
  2. 1,000円/回は「安さで勝負」ではなく「まず5人に来てもらうためにハードルを下げる」ための価格
  3. 「経験者限定」は最大の強みだけど、人が集まらない場合は3ヶ月後に条件を広げるかどうかを判断する
  4. 一番怖いのは「人が集まらない」ことではなく「何がダメだったかわからないままやめてしまう」こと。記録を取りながら小さく回す
  5. 自分のSNS発信より、参加した人が「今日めっちゃ楽しかった！」と自分から投稿したくなるレッスン体験を作る方が10倍大事

Stage 2: 興味 — 「自分に合いそう」と思ってもらう

  • 先生の人柄が伝わる投稿（自己紹介、想い）
  • 「初心者クラスだと物足りないよね」的な共感できる投稿

  • 開講記念：初回3名まで体験無料、以降500円

  • 不安解消FAQ投稿（「体力不安でも大丈夫」等）

Stage 4: 継続 — コミュニティの一員になってもらう

  • レッスン後にLINEで「今日はありがとう！」＋振付動画を送る

結局なにをすればいい？（まとめ）

最優先（今すぐやること）

  1. クラス名を「REBOOT DANCE」に決定し、Instagram・LINE・チラシで統一表記
  2. 最初の3名は既存人脈から確保する（SNSだけに頼らない）
  3. 格安スタジオ（1,500円/時間以下）を調査。公共施設・区民センターを優先
  4. Instagram+LINE公式の2アカウントを開設する
  5. ダンス動画3-5本を撮り溜めして投稿のストックを確保

開講後に意識すること

  • 「経験者限定」のポジショニングを曖昧にしない（差別化の根幹）
  • 1,000円/回は参入価格。6ヶ月後に1,500円への改定を計画
  • レッスンの「質」より参加者が「また来たい」と思える体験設計が重要
  • インストラクター本人の顔出しコンテンツが最も効果的
  • 完璧を目指さない。スマホ1台で撮影・編集・投稿を完結させる
  • レクリエーション保険（30円/人/回）への加入を推奨

「うまくいかないな」と思ったら

  • 3回連続で平均3人未満 → 対象を「25歳以上」に広げることを検討
  • Instagram 1ヶ月でフォロワー50未満 → ジモティー・ストアカに注力
  • メンバー3人以下が1ヶ月続く → 1ヶ月休止・再募集判断
  • 6ヶ月後に安定8名以上 → 週1回化＋価格改定＋2クラス目検討
